# ネクマックスの漢字アドベンチャー

漢字を **書いて** 集め、集めた漢字を **組み合わせて武器を作る** 学習ゲーム。
カンボジアのIT専攻の学生（日本語学習歴1年・N5〜N3）向け。

> 漢字を学んで、武器をふやして、つよくなろう！

`tomy1031/kanji_go` のなぞり書きエンジン（hanzi-writer）を土台にしています。

---

## 遊びかた（1ステージの流れ）

```
ストーリー  →  書取り 10回 × 新しい漢字  →  合成  →  戦闘  →  報酬
（ノベルUI）     （漢字を手に入れる）      （武器を作る）  （書いて戦う）  （ジェム・なかま）
```

- **漢字は書取り10回で手に入る。** 3回以上まちがえた回は数えません。
- **武器は漢字2〜3字の組み合わせで作る。** 同じ組み合わせは必ず同じ武器になります。
- **戦闘の威力は「書けたかどうか」で決まる。** 一発なら1.5倍、3回まちがえると反撃されます。
- **ジェム**はデイリータスクとステージクリアで貯まり、ネクマックスの個体ガチャに使います。

## 武器合成の考えかた

618字 × 618字 = **381,924通り**の2字組。3字を入れれば事実上無限です。
そのうち **4,893通りは実在する常用熟語**（EDICT2 から抽出）。

| 組み合わせ | 結果 |
| --- | --- |
| `火` + `山` | **火山（かざん）volcano** — 実在の言葉。★4の剣。「本当にある言葉！」と意味が出る |
| `山` + `火` | 言葉にならない。★1の槌。武器にはなるが、はっきり弱いと明記する |

**語順が意味を持ちます。** 1字目の意味（英語の語釈から機械的に導いた属性）が武器の形を決めます。

N5の85字だけでも **347語** が作れるので、最初のステージ群を終えた時点で合成は十分に遊べます。

## 3部構成

| 編 | JLPT | 世界 | 状態 |
| --- | --- | --- | --- |
| むかし編 | N5（85字） | 村・山・高い木。絵本が正典 | **10ステージ 実装ずみ** |
| 現代編 | N4（166字） | インターネットで夢を信じたネクマックス | 器のみ |
| 未来編 | N3（367字） | 家庭用ロボットとして普及した時代のSF | 器のみ |

むかし編は、いただいた絵本6ページを正典として脚色し、7〜10話で続きを書いています。
枝のない大木は「村で覚えた字をきざんで足がかりにする」ことで登ります。

## テストが守っていること

データの正しさは目視ではなく機械で見ています。

- 本文の漢字に **ふりがなが1つも欠けていない**（`unreadKanji` が0件）
- 10ステージが **N5の85字をちょうど1回ずつ** 配っている
- ノベルの **分岐の行き先が全て存在する**（行き止まりがない）
- 武器アイコン名が **実在し、バンドルに含まれている**
- 戦闘の威力が **書取りの精度に支配されている**

## ディレクトリ

```
src/components/   なぞり書きキャンバス・ふりがな表示など共通UI
src/features/     画面（title / map / novel / write / forge / battle / gacha / collection / daily / settings）
src/lib/          エンジン（forge / battle / srs / ruby / strokeLoader）
src/data/         漢字台帳・熟語辞書・ステージ表・脚本・個体
src/store/        セーブデータ（zustand + localStorage）
scripts/          データ生成・アセット変換・通しプレイ
docs/skills/      画像生成プロンプト台帳
```

**セーブデータは入力だけを持ちます。** 武器はレシピ（どの漢字をどの順で）で保存し、
名前・性能・絵は読み出し時に導きます。調整を変えると、手持ちの武器もそれに追従します。
