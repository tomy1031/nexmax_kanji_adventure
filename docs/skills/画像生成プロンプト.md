# 画像生成プロンプト（Codex / image-gen-2）

> **2026-09-25: 作業表は `docs/画像素材リスト.md` に 移した。** 何を・どこに・どの 順で 撮るかは
> そちら（`scripts/art/manifest.mjs` から 自動で 書かれる）。ここは 規律と 経緯の 正典として 残す。
> 下の §1（仮の 絵の 一覧）と §3（背景を 1920x1080 横で 撮る）は **古い**: いまの 背景は
> 縦持ちの 絵本（1024x1536 で 撮り、奥 bg と 手前 fg の 2枚に 分ける）。

このゲームの絵を **あとで** 作るための台帳。いまは仮の絵（絵本の原画・ネクマックス立ち絵・
Game Icons のフリー素材）で動いている。ここに書いてあるプロンプトで撮り直すと、仮の絵を
本番の絵に差し替えられる。

出どころ: NexmaxAcademy の `docs/skills/codex_image_generation.md`（運用実績のある本体）。
**規律はそちらが正典**。ここはこのゲーム固有の差分だけを持つ。

---

## 0. 絶対に守ること

1. **キャラクターを手描き SVG で自作しない。** ネクマックスは必ず image-gen-2 で生成する。
2. **参照画像を必ず入力に渡す。** テキストだけで再現しようとしない。
3. **マスター記述ブロック（§2）は逐語コピー。** 要約・言い換え・翻訳をしない。
4. **差分は1回に1つだけ。** ポーズ変更とアイテム追加を同時にしない。
5. **受入チェック（§7）に落ちたら、直さずに撮り直す。** 部分修正は絵柄の崩れを溜める。
6. **1セッションで1グループをまとめて撮る。** セッションが変わると傾向が変わる。
7. **「タイ」という国名を、文言にも画像にも画像生成プロンプトにも使わない。**

### 参照画像（必ず添付する）

| ファイル                                | 役割                                              |
| --------------------------------------- | ------------------------------------------------- |
| `public/img/chara/nexmax.webp`           | 正典。ネクマックスの原画                          |
| `public/img/chara/build.webp`            | 合格ずみバリアント。**場面画のときは必ず足す**    |
| `public/img/chara/variants_sheet.webp`   | 職業ちがいのネクマックス20体の設定画              |
| `public/img/bg/mukashi_*.webp`           | むかし編の絵本6ページ。**むかし編の画風の正典**   |

> **既知の失敗**: 場面の中にネクマックスを描くとき、原画1枚だけを参照にすると
> 頭が卵形になり白い顔面が小さくなる（NexmaxAcademy で 2026-08-30 に実発生）。
> **合格ずみのバリアント（`build.webp` など）も参照に足す**と、横長ヘルメットと
> 大きな顔面が戻る。

## 1. いま仮で使っている絵（差し替え対象の一覧）

| 用途                       | いまの中身                                        | 差し替えの優先度 |
| -------------------------- | ------------------------------------------------- | ---------------- |
| タイトル背景               | `bg/title_keyart.webp`（提供された原画）          | 低（完成度が高い） |
| むかし編の背景6枚          | 絵本の原画（**文字が焼き込まれている**）          | **高**           |

## 2. マスター記述ブロック（逐語使用・変更禁止）

NexmaxAcademy の正典をそのまま使う。プロンプトは必ず「この全文 ＋ 差分1行」の形にする。

```text
Character: "NexMax", the official robot mascot of NEXT MAKE.
Style: hand-drawn sketchy black outline (slightly rough, warm line, approx 6-8px at 1024px),
flat cel colors with soft minimal shading, cute chibi proportion (big head, about 2 heads tall),
soft drop shadow under feet, plain white background, no readable text anywhere.
Anatomy (must match the reference image exactly):
- Rounded helmet-like head, wider than tall, light sky-blue (#A9D6F5) with soft shading (#7FB8E8).
- Two small rounded ear pods on the sides of the head.
- Large white rounded face-screen covering most of the face, with a soft notch dipping at the top center.
- Two black oval eyes, thin curved eyebrow marks on the helmet above the screen, small gentle smile.
- Small trapezoid torso in the same sky-blue, with the NEXT MAKE chest mark:
  a navy (#004F8D) double-peak "M" logo (two triangular mountain shapes).
- Segmented ball-joint arms with round elbows and mitten hands.
- Short segmented legs with rounded boots.
Mood: friendly, curious, encouraging. Kid-safe, e-learning mascot.
Never: realistic rendering, gradients, extra fingers, readable letters, dark horror tone, angry face.
```

### このゲーム固有の追記（マスター記述の直後に足す）

胸のマークは物語の装置（傷ついたとき、ここから光を出して異空間の入口を作る）なので、
**胸のマークを隠す構図にしない**。

```text
Game-specific: the navy chest mark must always be visible and unobstructed —
it is a story device that emits light. Never cover it with props, arms, or clothing.
```

## 3. 背景（ノベルゲームの舞台）

### 共通の描画仕様

```text
Output: 1920x1080 landscape, no characters, no readable text anywhere, no watermark, no logo.
Composition: the lower third is kept visually simple and low-contrast — a dialogue box
sits there and the art must not compete with it. Horizon placed high.
Lighting: single consistent light source. No lens flare over the lower third.
```

> **重要**: ノベルゲームのテキストボックスは画面下 1/3 を占める。そこに細かい絵を置くと
> 文字が読めない。**下 1/3 は「単純で、コントラストが低い」**と毎回書く。

## 5. ネクマックスの個体（ガチャで手に入るキャラ）

いまは Academy の16タイプ立ち絵（`public/img/chara/types/`）を当てている。
このゲーム用に撮り直すなら、Academy の規律をそのまま引き継ぐ:

> **素体は動かさない。** 顔・目・胸のMマーク・関節・頭身は現行の立ち絵と同一。
> 変えるのは **装備＋ポーズ＋色** の3つだけ。

参照入力は3枚: `nexmax.webp` ＋ 置き換え元の立ち絵 ＋ 合格ずみの同グループ1枚。
色は16進で指定せず、**「参照画像の空色を◯色に置き換え、他はすべて同一に保つ」と差分で言う**
（そのほうがぶれが小さい。Academy の実績）。

**性別差分を作るなら5点のみ**（アンテナの曲がり／耳パッド横の小花／プリーツスカート／
まつげ／重心）。**体型を変えない。表情の性格づけを変えない**
（能力や性格の差に読める差分を絵に入れない）。

## 6. 武器アイコン

いまは Game Icons（CC BY 3.0）を使っている。**当面はこれで足りる**（4040種）ので、
生成の優先度は低い。撮るとしても「レアな熟語武器」だけにする（数が多すぎる）。

```text
Flat vector game item icon, centered on a fully transparent background.
Single weapon, three-quarter view, bold clean shapes, thick dark outline,
flat cel colors with one highlight, no gradients, no shadow, no text anywhere.
Kid-safe fantasy game UI icon, bright and friendly. 512x512.
```

差分は武器1つにつき1行（例: `Item: a short wooden practice sword with a cloth-wrapped grip.`）。

> **`no shadow` を必ず入れる。** Academy で `subtle drop shadow` と `flat vector` が矛盾し、
> 透過PNGに灰色の輪が残った。1枚直すなら16枚まとめて作り直す。

## 7. 受入チェックリスト（1枚ごと。1つでも落ちたら撮り直す）

### ネクマックスが写っているもの

- [ ] 頭部シルエットが**横長ヘルメット＋耳ポッド**（卵形になっていない）
- [ ] 白いフェイススクリーンが**顔の大部分を占め**、上中央にくぼみがある
- [ ] 胸に**紺のダブルピークM**があり、隠れていない
- [ ] 体色 `#A9D6F5` 系・ロゴ `#004F8D` 系で、余計な色が増えていない
- [ ] 手描き風の黒アウトラインの太さが揃っている
- [ ] 指が崩れていない・読める文字が無い・実在ロゴが無い
- [ ] 表情が友好的（怒り・恐怖・嘲笑が無い）

### 背景

- [ ] **下 1/3 が単純で低コントラスト**（テキストボックスが載っても文字が読める）
- [ ] 人物が写り込んでいない
- [ ] **読める文字が1つも無い**（看板・画面・本の中も含む）
- [ ] 編の画風から外れていない（むかし＝パステル／現代＝フラット／未来＝発光）
- [ ] 1920x1080

## 8. 起動のしかた

```bash
codex -i public/img/chara/nexmax.webp -i public/img/chara/build.webp \
  "image-gen-2 で画像を1枚生成してください。
   出力: 1024x1536 PNG, 透過背景, キャラ中央・全身。
   保存先: public/img/chara/nexmax_think.png
   色ムラ・線のゆれ・大きさを理由に作り直さないこと。ちょうど1回だけ生成する。
   プロンプトは以下（逐語使用）:
   <§2のマスター記述ブロックを貼る>
   Pose: standing, one mitten hand near the side of the face-screen, eyes looking up and to the side, mouth a small flat line."
```

> **色ムラを理由に再生成させない**旨をプロンプトに明記しないと、Codex が延々作り直して
> 保存されない（Academy で実発生）。

### 生成後

```bash
node scripts/prepare_assets.mjs   # web サイズの webp へ変換する
```

PNG のままだと1枚 850KB になる。**必ず webp にしてから PNG を消す。**
