# 制約と好みの台帳

とみさんが口にした制約・好みを、言われた日付とともに残す。
**作業を始める前に必ず読む。** セッションをまたいで記憶は残らないので、ここが唯一の引き継ぎ。

新しく制約を聞いたら、その場でここに足す。消すときは「いつ・なぜ外したか」を書いてから消す。

## 進めかた

- **PR とマージは Claude が行う**（2026-09-17）。とみさんは許可を出す側で、GitHub の操作はしない。
  検査（typecheck / lint / test / build）が緑になったら、PR を立てて `main` へマージするところまで進める。
  `main` へ入ると GitHub Pages へ自動で出る（`.github/workflows/deploy.yml`）。
- 確認をお願いするときは、**とみさんが見られる形（公開URL）まで進めてから**。
  動くかどうかの確認をさせない。見てほしいのは中身（遊びとして面白いか、学べるか）。
- ステージや仕組みを足す・並べ替えるときは、**並びを before → after で書いてから**着手する。
  並びは「足した順」ではなく「前提が揃う順」。

## このゲームの決まりごと

- **書取り10回で漢字を入手**（2026-09-16）。これは変えない。
  「戦闘に行くまでに何字要るか」は別の話で、こちらは調整してよい（いまは3字）。
- **ガチャは10連**（2026-09-17 の指摘で単発から変更）。
- **ネクマックスの個体**はステージクリアと、デイリータスクで貯めたジェムのガチャで手に入る。
- **武器は漢字の合成で作る。** 実在する熟語が非語より強いこと
  （関係ない3字が正しい2字に勝たないこと）はテストで固定してある。
- **対戦は kanji_go から移植したもの**を使う。ただし **kanji_go の Supabase の鍵は移さない**
  （ロビーが混ざる・他プロジェクトの資源）。理由は `docs/versus.md`。

## 見た目（2026-09-23）

- **UI は `public/img/design/` の参考画像に極力寄せる**（タイトル・N5をえらぶ・ステージ選択・
  お話・書く・バトル・合成・そうび）。青空と浮島、羊皮紙のパネル、木の看板、オレンジの主ボタン、
  青い副ボタン、下の4つのタブ。
- **むかし編のお話は、JS で動く絵本にする。** 元の絵本（`nexmax_kanji/`）の色あいを残し、
  切り絵（ちぎった紙のふち・紙の目）のテイストでよい。「多少 荒くても よいが、できれば すこし 丁寧に」。
  ネクマックスの絵は **手で描かない**。既存の画像（`public/img/chara/`）を切り抜いて使う。
- **書き取りは「字が 刃になって 岩を 斬る」。** 書いた線が 岩に 斬りつけ、書ききると 岩が 割れ、
  中から 漢字の マテリアル（かけら）が 出る。10回で その字が 手に入る（10回の決まりは そのまま）。
- **すべての 漢字に ふりがなを つける。** 画面の 文言も、大きく 見せる 漢字1字にも。
- **ステージ選択では「漢字(かんじ)れんしゅう」と「ストーリー（バトル）」を えらべる。**

## チュートリアル（2026-09-23 の指定）

- 0話で「一」を 手に入れたら、**その字で「一(いち)の 太刀(たち)」を 作る**。
- そのあと 会話を 少し 進めて **敵が 現れ、戦いが 始まる**。
  （以前の 0話は「新概念は1つだけ・合成は出さない」だったが、この指定で 上書きした。
  並びの before → after は `docs/design/06_チュートリアルの理解設計.md` §7）

## 2026-09-23（2回目）の 指定

1. **刀に 効果音。斬りつけるように。**
2. **装備は 複数 身につけられる**（`public/img/design/ネクマックスのそうび画面.png`: 武器・盾・からだ・アクセサリ）。
3. **「実在する熟語」が 怪しいものが 多い** → 熟語表を JLPT N5〜N2 の 語彙に 載っている 語だけに 絞った
   （`scripts/build_compounds.mjs`。土人・一女・中前・高見 などが 消えた）。
4. **ステージごとに どんな 強化が できるかを 決め、段階的に 強くなる 仕組みに する。**
   最初は ヒントを 出して、**新しい 漢字で 強くなる ことを 学ばせる。**
5. **戦いで 練習した 漢字しか 出ないと、練習が 少ない ほうが 有利に なる。**
   練習して いない 漢字で 困る ほうが よい。ここは 工夫する。
6. **送りがなが 要る 字（大きい）で「おお」だけ 出るのは 変。読みは 複数 あるので、それぞれ 出す。**
7. **背景も 動く 絵本に。木々が 少し 動く など。**
8. **敵は、プレイヤーが 一定数 ミスを したときに ダメージを 与える。**
9. **現代編に 着手する。**
10. **N5 レベルで 日本語が 読めない 生徒への 配慮。ただし 全部 英語に すると 英語しか 読まなく なるので 工夫する。**

## 現代編

- **暴力は 直接 描かない。ただし 怖い 雰囲気は そのまま 残す**（2026-09-23 に決定）。
  2026-09-16 に提起した判断待ち（原作漫画 #1 で 先輩が 新人の 頭を たたく 場面）への答え。
  案A（暴力だけ外し、叱られる場面は残す）に近い。たたく 動作は 描かず、声・表情・間(ま)・
  周りの 空気で 怖さを 出す。詳細は `docs/design/現代編の構成メモ.md` §1。
- **原作は ネクストメイクの サイトと Instagram の 漫画「夢を信じたネクマックス」**（2026-09-24。
  「ネクストメイクウェブサイトにあります」「登場人物もいくつかいます」「他の話もあるはず。NEWSからリンクたどれるかも」）。
  公開は #1〜#5。**登場人物・出身・話の 順は 原作に 合わせる**（仲間は ソネ・ナラ・イグーチ、ネクマックスは 大阪から）。
  原作に ない 名前や 設定を 作らない。
- **漢字は 漢字だけで 見せる。読みがなは 添え物**（2026-09-24。「漢字の 送りがなを 文字の ところに
  表示するのは 違う。漢字は 漢字、添え物として 読みがななどが あるのが 大切」）。
  字の 場所には 字と 上の ふりがな だけ（大(おお)きい と 並べない）。送りがなは 読みの 一覧と 例の 語で 見せる。
  → 上の 6.（2026-09-23）の「大(おお)きい と 語で 出す」は これで 置きかわる（読みを 複数 出すのは そのまま）。
- **バトルでは 短い 語の 穴埋めで 出す**（同日「短い 例文の 穴埋めの ような 表示とか、バトルの 時は 良いかも」）。
  会□（□の 上に しゃ）→ □に 入る 字を 書く。
- **読みは レベルに 合った ものを 出す**（同日「やしろ（社 しゃ が 正しい）とか、レベルに 適切で ない 読み」）。
  辞書の 並び順では なく、JLPT N5〜N2 の 語で 実際に 使われる 読みから 選ぶ（`scripts/build_readings.mjs`）。
  N2 の 語でしか 出ない 読みは 出さない。
- **見た目を 商用 レベルに**（2026-09-24「今の UIや ビジュアルの 質や タイトル画面の 質を 商用レベルに 上げる」）。
  ロゴは 太い 看板文字（Dela Gothic One）を 2枚 重ね（こげ茶の ふち＋金の グラデーション）、
  メニュー画面は 平らな 色を やめて 後ろに 動く 絵本（<Backdrop>）、カードは 羊皮紙、見出しは 木の 札と 赤い リボン。
- **動線と 動きを アプリゲームとして 成立させる**（2026-09-24「動線 その他の 動きに ついても、アプリゲームとして 成立するように」）。
  勝ったら「つぎの 話へ」→ 地図で 新しい 話が NEW で 光る。負けたら「れんしゅうする」が 主。
  もどる・ストーリー・つづきから は 最後に 遊んだ 世界へ（むかし編 固定に しない）。ボタンは 押すと 音が 鳴る。
