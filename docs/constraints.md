# 制約と好みの台帳

とみさんが口にした制約・好みを、言われた日付とともに残す。
**作業を始める前に必ず読む。** セッションをまたいで記憶は残らないので、ここが唯一の引き継ぎ。

新しく制約を聞いたら、その場でここに足す。消すときは「いつ・なぜ外したか」を書いてから消す。

## 進めかた

- **PR とマージは Claude が行う**（2026-09-17）。とみさんは許可を出す側で、GitHub の操作はしない。
  検査（typecheck / lint / test / build）が緑になったら、PR を立てて `main` へマージするところまで進める。
  **main への マージは 承認なしで 行う**（2026-10-02「メインマージは承認なしでやって」）。CI が 緑なら そのまま マージして、何を 入れたかを 報告する。
  `main` へ入ると GitHub Pages へ自動で出る（`.github/workflows/deploy.yml`）。
- 確認をお願いするときは、**とみさんが見られる形（公開URL）まで進めてから**。
  動くかどうかの確認をさせない。見てほしいのは中身（遊びとして面白いか、学べるか）。
- ステージや仕組みを足す・並べ替えるときは、**並びを before → after で書いてから**着手する。
  並びは「足した順」ではなく「前提が揃う順」。
- **問題点・改善点は 自分で 見つけて 直し続ける。基準は スマホゲームとしての 商用基準**（2026-10-02
  「現状の問題点、改善点見つけて対応進めて」「基準はスマホゲームとしての商用基準」）。
  新しい プレイヤーとして 最初から スマホの 画面で 遊んで 撮り、見た目・手ざわり・動線・重さ・
  ストアに 出せる 体裁（アイコンなど）の 順に 直す。

- **町の 人は 人**（2026-10-03「町の 人は ネクマックスタイプで なくても 良い」）。なかまの ロボット（types の 16体）と
  見分けが つく ように、町の 人は 人の 絵（同じ つやの ある 塗り）。工場の 七ばんだけ ロボットの まま（なかまに なる）。

- **書くと 町が 変わる**（2026-10-02「もっと 文字を 書く ことで 文字が 灯る 演出も 必要…明確に 町の 景色が 変わったり、キャラクターの
  名前が 変わったり、表示前は 極端に 名前が 出ないのが 困る 演出」「ユーザーは 日本語を 理解できません。極力 画面上の 絵で
  ストーリーを 理解する 作りに」）。町の 絵の 看板（scenes.ts の signs）は 書いた 字で 灯り、まだの 看板は 暗い。

  光るだけ」）。光るのは 看板の 面だけで、字は ふつうの 太さ。

## 言葉の 意味と 読みやすさ（2026-10-04）

- **言葉の 意味の 英語は はじめから 出す**（「言葉の意味の英語はデフォルトでONにします」）。設定 `settings.english`（既定 ON、
  古い セーブにも ON）。図鑑の 漢字カードの EN と、ストーリーの ？ことば が 開いた 状態で はじまる。設定で 消せる。
  文 まるごとの 英語（ストーリーの EN）は これまで どおり ボタンで 開く（08 §3.5）。
- **単語の 意味を 見やすく**（同日「単語の意味の視認性が悪い」）。英語の 意味は 丸ゴシックの 太字・青（#1b4f8f 系）で、
  12px より 小さく しない。戦闘の 意味は よみの 下で 大きく（短い 語ほど 大きい）。
- **？ことば は 語で 引く**: 1字ずつ ふりがなを 付けた 語（学(がく)生(せい)）は つなげて「student」と 出す（「study / life」に しない）。

## 武器の 強さ（2026-10-04）

- **武器は ステージを 進むほど 強い**（「武器の強さはステージを超えるごとに強くなる設計」）。本当に ある 言葉の 武器は、
  いちばん 新しい 字の 話（1話＝1 … 11話＝11）で こうげきが ×1.0 → ×1.8（1話ごとに +8%）。2章から 先は 1話 +2%、×3 まで
  （`src/lib/forge/stage.ts`）。言葉に ならない 組み合わせは 上がらない ので、「本当の 言葉は いつも 強い」は そのまま。
- **かくし武器**（同日「それぞれの ステージの 漢字でも 隠し武器のような 形で 強いものが あると いい」）: 1話に 1つ、
  その 話で はじめて 作れる 言葉（`src/data/hiddenWeapons.ts`）。かならず ★5、こうげき ×1.3。その 話までに 作れる どの 武器より 強い（テストで 確認）。
  ヒントには 出さない。図鑑に 見つけた 数（n / 11）だけ 出す。
- **武器の ならべかえ**（同日）: つよい 順（はじめ）・★の 順・あたらしい 順・ステージ 順。もちもの と 図鑑で 同じ 順。この 端末に おぼえる。

## ストーリーの 文の レベル（2026-10-04）

- **1章の 文は みんなの日本語 1冊目の 文型まで**（「みんなの日本語の進行レベルに合わせて理解できる」）。受け身（たべられた）・ば・なら・
  可能形（かけます・よべます）・かもしれません・〜ていく・と（条件）は 使わない。〜です・〜ます・〜ません・〜ましょう・あります／います で 言う。
  〜て ください・〜て います は 決まった 言い方 として 使って よい。
- **英語に しか ない すじは 日本語でも 言う**（例: 1話「……あれは？ ちいさい くろい かげ……。」、2話「ぼくが つくります！」）。
- **同じ ことを 2回 言わない**（1話の おわりに 聞いた 金・土を 2話の はじめで もう 一度 言わない、5話の ずかん の 2行 など）。
  決まった 流れ（〜が ひかります → あなたは かきます。ぼくが たたかいます！）と、課の 文型を 練習する 行（はじめまして・何ですか）は 残す。
- **お話で 言った ことは 画面でも そう なって いる**: 5話「ずかんに、ぶきと なかまが あります」→ ずかんに「ぶき・なかま」ボタン。

## 説明は 1つずつ（2026-10-04）

- **じゅんびの 説明も 1つずつ**（「じゅんびの説明も1つずつ出す形にして」）。はじめての じゅんびで ★の ひみつ・たたかいの ひみつ（8つ）を
  まとめて 出さない。じゅんびでは 1回に 1つ（手本なしで 書く → ★で こうげき → あいては ★が 少ない 字を ねらう）。
  たたかいの 中で おこる こと（ミス→こうげき・COMBO・読みの もんだい）は、はじめて おきた ときに 上に 1行（4秒）。
  それぞれ 1回だけ（`tipsSeen`）。2ページの ひみつは じゅんびの ボタンで いつでも 見られる。前に 2ページを 読んだ 人には 出さない。

## 2026-10-07 の 指定

- **「音だけ 残って います」は 言わない**（「音しかありませんという表現はいらない気がする。漢字がないから読めない、わからない」）。
  各話の「にち、げつ……」の 行は「……かんじが ありませんから、わかりません。」に した。`src/data/textLevel.test.ts` が「おとだけ」を 見つける。
- **文の レベルを みんなの日本語に そろえる**（「もう少し文章をみんなの日本語のレベルに準拠した文法や単語レベルに」）。
  なかまの ひとこと・わざの 説明も 1冊目の 文型と やさしい 語に した（〜こう・命令形・可能形・みたい は 使わない。テストで 確認）。
  可能形（よめません）は 27課 なので、4章まで 使わない。
- **強い 武器でも 字を 書かずに 勝てない**（「強い武器作るとあっという間にひっくり返った気になってしまう…今のままでは漢字の練習としてできない部分も出る」）。
  **字の ふういん**（`src/lib/seals.ts`）: モジクイは その たたかいで 聞く 字を「お札」として もつ。もって いる 字を 先に 聞き、
  ぜんぶ 1回ずつ 書くまで たおれない（HP は 字の 数で 分けた 分を のこす）。強い 武器は「字の 数より 多く 書く」回数を へらすだけ。
  ふつうは その 話の 字 ぜんぶ、ハードは HP を 決めた 字（いちばん 書いて いない 字から 話の 字数ぶん）、まとめの ボスは ねらう 10字。
  お札は HP の 下に 🔒 で ならび、書くと 字に かわる。ぜんぶ 開くと 🔓 1つに たたむ（のこりの たたかいで 字を 見て 写せないように）。
