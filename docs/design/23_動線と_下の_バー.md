### 1.2 見つけた こと

1. **たいせんに 行けない**（いちばん 大きい）。上の とおり、ガチャの 本の 下に かくれて いる。本番は 中継が ある ので、
   1章を クリアした 人 みんなに おきて いる。
2. **主役が 小さく、遠い。** つぎの 話は 吹き出し 1つ。同じ 高さで ガチャの 本が 光って ゆれて いて、目が そちらへ 行く。
3. **バーが ハブ だけ。** 新ルートの もちもの（`EquipScreen`）は `BottomTabs` を 出さない（`!moji`）。ほかの 画面は「もどる」だけ。
   むかし編の 4つの タブ（ストーリー・漢字ずかん・そうび・せってい）は 古い 編に だけ 残って いる。
4. **バーの 絵に 文字が 焼いて ある**（`public/img/stageselect/menu.webp`）。中身を かえる・鍵を つける・バッジを 出す たびに 絵を 作り直す ことに なる。
   いまの 5つ（ステージせんたく・もちもの・ずかん・せいせき・せってい）に ガチャ・まいにち・たいせんの 場所が なく、絵の 上に 浮かせた。これが 1. の もと。
5. **鍵が 見えない。** はじめての 人の ハブには、ガチャ・まいにち・たいせんの しるしが 何も ない。ない ものは 楽しみに できない。
6. **ガチャの 主な ボタンが 画面の 外**（1.1）。
7. **1つの 行き先に 名前が 3つ・にた 絵が 2つ。** もちもの（ハブ）・そうび（むかし編の タブ）・持(も)ちもの（漢字やさん）。
   ずかんの アイコン（ひらいた 本）と ガチャの 入口（ひらいた 本）が にて いる。
   ずかん →「ぶき・なかま」と もちもの →「図鑑（なかま）を 見る」は 同じ 画面（`/collection`）。
8. **「ステージせんたく」の ボタンは ハブでは 何も しない**（一覧を とじる だけ）。いちばん 大きい ボタンが 空っぽ。
9. **小さい 押す ところ**: まいにち・たいせんの 札 81×32px、まいにちの「▶ いく」60×30px。
10. **称号の ◆ が 見えない。** せいせき の まどの 中。称号の 画面は 4685px の 長さで、うけとれる ものが どこか わからない。
11. 右上の 行き先の 案内板は x=790〜980（941 の 外へ はみ出す）で、右が 切れて いる（「シンガポー」）。押せない かざり。

## 3. 提案

### 3.1 どこに 何（全体）

| 置き場 | 中身 |
| --- | --- |
| **下の バー**（ハブの 画面 ぜんぶ） | もちもの・ガチャ・**ステージ（まんなか、大きい）**・ずかん・たいせん |
| **上の 左**（ハブ だけ） | ネクマックスの 札（顔・Lv・クラス）→ せいせき（称号）。その 下に ◆ の 数 |
| **上の 右**（ハブ だけ） | ⚙ せってい。その 下に **まいにちの 掲示板**（いまの 行き先の 案内板を つかう） |
| **まんなか**（ハブ） | 物語だけ: 看板・行き先の 看板・旅の ネクマックス・地図の カード・「▶ つぎの 話」 |
| **その 画面の 中** | 漢字やさん・かなの かじや（もちもの と じゅんび から）。ことば図鑑・ぶき・なかま（ずかん の 中）。称号（せいせき の 中） |

なぜ この 並びか:

- **ステージを まんなかに。** 左右 どちらの 手でも いちばん とどく。物語が 主役（08）。いまの 絵の「左の 大きい 円」は 見本ゆずりだが、
  左の はしは 片手で いちばん とどかない。
- **ガチャは 2番目**（まんなかの となり）。きょうの むりょう で 毎日 来る 場所。バッジが 目に 入る 所。
- **たいせんも バーに。** たいせんは 1つの 画面（ロビー・へや・CPU）で、きまった 場所が 要る。鍵つきで はじめから 見えて いると「1章の あとで ひらく」が 楽しみに なる。
- **まいにち は バーに 入れない。** 中身は「きょうの リスト」で、ようす（何が おわったか）を 見せる ほうが 役に 立つ。ハブの 掲示板なら 開かずに ○✓ が 見える。
- **せってい・せいせき は 上の すみ。** めったに 押さない。バーの 場所を とらない。

## 5. あぶない ところと 作る 順

**あぶない ところ**

- テストで ハブの 置き場を 決めて いる ものは ない。ただし `mojiFlow.test.ts` は 話の あとの 行き先 `/map/moji?new=…`・`?at=…`
  （シートが ひらいた まま 来る）を 決めて いる。この 動きは のこす。`appUpdate.test.ts` の 道すじの 一覧は かわらない。
- **はじめての ガチャ**: 暗く して チケットの ボタンだけ 上に 出し、上の 板から 👇 で さす（`GachaScreen` の coach）。
  ボタンが 下の 固定の 列に 動くと 👇 が ずれる。板を ボタンの 上へ 動かす。
- 漢字やさん（`/forge?first=1`）と ガチャ（`/gacha?first=1`）の はじめては お話から 直接 行く。バーは かかわらない。
- `GearHint` は じゅんび から `/equip` へ 行く。もちもの に バーを 出しても「◀ もどる」で じゅんびへ もどれる ように（もどる を 消さない）。
- バーの 重なり: 称号の ポップアップ（上）・クラスアップの おしらせ・まど（z-40 いじょう）が バー（z-30）の 上に くる ように。
- バーの ある 画面は 下を あける。とくに たいせんの ロビー（いまの「ともだちと」が かくれる）。
- `nexmax-features-opened` は 名前を かえずに つかう（もう 見た 人に NEW を 出さない）。
- かな編の 人の 札の 顔（★1・★2）は、ハブの 旅の ネクマックスと 同じ きまりに する（22 §2。どちらに するかは かな編の 作業で きめる）。

**作る 順**（前提が そろう 順）

1. **いますぐ の 小さい 直し**: たいせんの 札が ガチャの 本の 下に ある。バーが 入るまでの つなぎに、たいせんの 札を 右へ
   （`fromTop(720, 670, 196, 78)`、つぎの 話の 吹き出しの 下。SE でも 地図に かからない）。
2. **絵**: `NAV_ICON` と `NAV_ART` を 台帳に 足して Codex で 作る → `import.mjs`（`hub_bar`・`hub_go_plate` は 大きく）。
3. **バーの 部品**（`components/ui` に 新しく。5つ・鍵・バッジ・NEW・光る 場所）。まず ハブの `menu.webp` と 入れかえ、
   ガチャの 本・まいにち／たいせんの 札を ハブから はずす。
4. **ハブの 上と 主役**: 左上の 札（→ せいせき）・◆・⚙・まいにちの 掲示板・「▶ つぎの 話」の 板・カードの 置きなおし。
5. **ほかの 画面に バー**: もちもの・ガチャ・ずかん（ことば図鑑・ぶき・なかま）・たいせんの ロビー・まいにち・称号。♛ ホームを はずし、下を あける。
6. **ガチャの ひく ボタンを 下に 固定** ＋ はじめての チケットの 👇 を 合わせる。
7. **もちもの**: 題「もちもの」・漢字やさん と かなの かじや の 2つの ボタン・かなの ぶきの わく（かな編の ぶきの 作業と いっしょに）。
8. **見なおし**: 3つの セーブ（はじめて・中ごろ・おわり）× 3つの 画面（390×844・375×667・1180×820）で 撮る。
   たいせん・まいにち・ガチャ・せいせき・せってい が 1タップで 開く こと、かさなりが ない こと（`elementFromPoint`）。test・lint・tsc。
