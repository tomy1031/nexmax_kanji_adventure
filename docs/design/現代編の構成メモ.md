## 1. 暴力描写の扱い（2026-09-23 に決定）

> **決定: 暴力は 直接 描かない。怖い 雰囲気は そのまま 残す。**（とみさんの指定）
>
> - たたく・つかむ・物を投げる などの 動作は 絵にも 文にも 出さない。
> - 怖さは **声（大きな 声・短い 言葉）・表情（黒く 塗られた 顔）・間（ま）・周りの 空気**
>   （だれも 動けない、時計の 音だけ 聞こえる）で 出す。
> - 下の 案A に近い。以下は 判断の 経緯として 残す。

### 経緯（判断待ちだったときの メモ）

原作には、**先輩が新人の頭をたたく**場面がある（#1「三人遅刻者がいて／頭をたたかれている」
「いきなりお前らはなぜ遅れてるんだ!!」「ふざけてるのか!?」、
「トイレです」→「集合時間に間に合わないのであれば我慢しろ!!」）。

原作の中では **コメディとして、かつ「暗黒の」と題して誇張されたもの**として描かれている。
ただ、このアプリの読者は **これから日本で働く可能性のあるカンボジアの学生** なので、
そのまま教材に載せると「日本の職場ではこれが普通で、受け入れるものだ」と読めてしまう。

**3つの案**（ユーザーの判断を待つ）:

| 案 | 中身 | 得るもの / 失うもの |
| --- | --- | --- |
| **A. 暴力だけ外す** | 遅刻を叱られる場面は残し、たたく描写を「大声で叱られる」に置き換える | 原作の緊張感と「戸惑い」は残る。原作との差分が1つ増える |
| **B. そのまま載せる** | 原作どおり | 原作に忠実。ただし学習者が「これが普通」と受け取る恐れ |
| **C. 枠をつけて載せる** | そのまま載せた上で、章の終わりにネクマックスが「これは 正(ただ)しい やり方では ない」と言う場面を足す | 忠実さと安全の両立。ただし本文に無いものを足すことになる |

**いまの推し: A。** 原作の狙い（何が起きているか分からない戸惑い、同じ立場の仲間と分かち合うこと）は
たたく描写が無くても全部成立する。むしろ **「理由が分からないまま叱られる」ほうが、
学習者が実際に直面する困りごと（言葉が分からない・何を求められているか分からない）に近い**。

> むかし編にも同じ規律がある: **ネガティブな例を、名前のある登場人物にやらせない。**
> 現代編の「怖い先輩」は原作では顔が黒く塗られた匿名の存在なので、この規律とは衝突しない。
> 名前をつけないまま「影の先輩」として扱うのがよい。

## 2. 原作 #1 のあらすじ（読み取ったまま）

1. 入社式が終わり、全新卒者50名がそのままバスに乗り込んだ
2. 毎年恒例、九十日間の「研修合宿」の為、静岡県の富士山麓を目指す
3. ワクワクドキドキ新しい仲間たちとの「合同研修」が始まる——**はずだった…**
4. 着くとそこは富士樹海に囲まれた、周囲から孤立した研修所
5. 旅館のおばちゃんたちが暗い顔をしている（「なんで皆んなこんな暗い顔してるんだ?」）
6. 「早くジャージに着替えてこい！」「五分以内だ！」→「五分以内!? 早すぎじゃないか」
7. 宿に戻った時間がない為、ほぼトイレだけを済ませ集合場所の食堂に向かう
8. すでに怖い先輩達は食堂にいる。バスにいたのがこの三人の先輩達。そして——
   奥に座っているのが、おそらくボス達だ
9. **こういう時に必ず遅刻する人間は現れるものだ…** 三人遅刻者がいて、頭をたたかれている
10. 「何をしていたんだ!?」「ト、トイレです、、」「集合時間に間に合わないのであれば我慢しろ!!」
    →（ネクマックスの心の声）「えげつないな。。。」
11. 「よーし、整列しろっ!! 今から名前を呼んでいく！ 呼ばれたものからこっちに並べ！」
12. 腕立てをさせられるチーム以外は、先に部屋に戻り休めることに
13. 僕たちのチームも部屋に戻り——少しホッとして、自己紹介をし合うことに——
14. 「なんかちょっと何が起こってるのか分からないくらい戸惑っているんだ」
    「俺たちも一緒だよ」
    「これが先ずは一カ月続くのかな・・」「社会人ってこんなに厳しいのかな・・」

### この話の芯

**「何が起きているのか分からない」戸惑いを、同じ立場の仲間と分かち合う。**

これは学習者にそのまま刺さる。日本語も、日本の職場の作法も、最初は
「何を言われているか分からない」ところから始まる。原作はそれを笑いに変えているが、
**笑いの下にあるのは「一人じゃない」という発見**で、そこが教材としての価値になる。

## 3. ステージ案（10話・N4の166字）

順番は「前提が揃う順」。**#1 の範囲で 1〜5話、#2〜#5 を読んでから 6〜10話を確定させる。**

| # | 仮タイトル | 場面 | 漢字のテーマ |
| --- | --- | --- | --- |
| 1 | 入社式(にゅうしゃしき)の 日(ひ) | 式が終わり、バスに乗る。期待 | 会社・仕事・人の役割 |
| 2 | 九十日(きゅうじゅうにち)の 合宿(がっしゅく) | 富士山麓へ向かう車中。自己紹介の予感 | 数・期間・移動 |

| 4 | 五分以内(ごふんいない) | 着替えの号令。時間に追われる | 時間・命令・体の動作 |
| 5 | 分(わ)からない まま 叱(しか)られる | 食堂。遅刻者が叱られる。「えげつないな」 | 感情・音・声 |
| 6 | 自己紹介(じこしょうかい) | 部屋に戻り、チームの仲間と話す。**ここが転換点** | 名前・出身・趣味 |
| 7 | （#2 を読んでから） | | |
| 8 | （#3 を読んでから） | | |
| 9 | （#4 を読んでから） | | |
| 10 | （#5 を読んでから） | | |

**6話を山にする。** 1〜5話は「分からない」の積み重ね、6話で「俺たちも一緒だよ」が来る。
むかし編が「字を書けば登れる」で開けたように、現代編は「話せば一人じゃなくなる」で開ける。

## 5. 絵について

原作の漫画は **白黒・手描き・コマ割り**で、いまのノベルUI（背景＋立ち絵）とは形式が違う。
2つの道がある。

- **案1: 漫画のコマをそのまま背景に使う。** 手間が最小。ただし白黒でセリフが焼き込まれていて、
  むかし編と同じ「文字が二重になる」問題が起きる
- **案2: 場面だけを取り出して、ノベル用の背景を生成する。** `docs/skills/画像生成プロンプト.md` §3.2
  にある現代編の背景（`gendai_*`）を、原作の場面に合わせて撮り直す。立ち絵も新規

**推し: 案2。** ただし原作の絵柄（白黒・手描き）を **回想として使う**手はある——
たとえば各話の終わりに原作のコマを1枚出す。原作へのリンクにもなる。
