## 2. しくみ

- **VS**（`BossVsIntro`）: 2.7 秒（動きを へらす 設定では 1.6 秒）、タップで とばせる。なかまの「いっしょに たたかいます！」が 出て いれば その あと（3 秒まで 待つ）。
  なかまの あいさつ・0章の ことばの 読み上げは VS の あとから。
- **とちゅうの お話**（`BossBeat`）: 1行ずつ タップで すすむ。顔は 話の 名札と 同じ 切り抜き（ボスは 今の 絵）、EN ボタン。2回めは ゆれて 赤く 光る。
  光が あたった あと（★3 の 字の わざの 光の あとは 少し おそく）に 出る。1回の 書きで 2つ こえたら 2つ 続けて。
- **とどめ**（`holdForFinisher`・`FinisherCall`・`FinisherFlash`）:
  - たおれる はずの 一撃 → HP は のこり 3%（それより 少なければ 今の HP − 1、さいていでも 1。けっして ふえない）。字の ふういんの 決まりは そのまま（ふういんが のこって いる あいだは もともと たおれない）。
  - 「とどめの 一字！」の 帯と 大きな 字、ネクマックスの ひとこと。つぎの 字は とどめの 字（町は ほかの 章の 字でも よい: 5章の 友）。読む ターンは こない。
  - とどめの 字は うすい お手本の 上を なぞる（見せ場なので ためしでは ない）。ミスは かぞえず、反撃も ない。書きじゅんは ただで 見られる。★ や ふくしゅうには 入れない。
  - 書けたら 光の 柱と 白い 光 → 0 → いつもの 勝ち。
- **2段目の 絵**: とちゅう 2 が ひらいた ときから。Codex（`scripts/art/manifest.mjs`、もとの 絵と 同じ 枠 `matchFrame`）:
  `mojikui_boss_angry`（1〜4章 共通）・`mojikui_king_waver`・`mojikui_kana_starboss_angry`・`mojikui_kana_slurp_angry`。
  インクの すきまに のこる 白は `import.mjs` が 消す（敵の matchFrame でも enclosed）。顔の 位置は `face_crops.mjs` の OVERRIDES。
- **0章の 段の 数え方を なおした**: 段が ひらいたかは「その ことばを 書きはじめた とき」と くらべる（それまでは さいごの かなの 前と くらべて いたので、
  ことばの とちゅうの かなで 段が ひらくと 回復 40% も 出なかった）。`playKanaFight`（バランスの テスト）と 同じ 数え方。
- ネクマックスの とどめ「ネクマックス」には 小さい ッ が ある。その わくには ローマ字の かわりに ッ を 出し、かなの 書いた 回数には 入れない。
