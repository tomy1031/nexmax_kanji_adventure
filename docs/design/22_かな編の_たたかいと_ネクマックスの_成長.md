## 4. 0章の たたかい「きいて かく」

### 4.1 1回の 流れ

1. かげが ことばを なげる: 上に 英語の 意味（FACE）と ？ の 箱、下に ローマ字の わく（ka・o）。ことばの 音が 鳴る（端末の 声）。
2. ボードに 1字ずつ 書く（かなの ゆるい 判定 2.2、ふ・な・や は 3。§4.3）。正しく 書けた 字は わくに 入る（ローマ字の 上に かな）。
3. ことばが ぜんぶ 書けたら、？ が 絵（絵文字）に かわり、ネクマックスの こうげき。きれいに 書くほど 強い（ミス なし ×1.5 …）。
4. 1字の はじめの ミスは 数えない。2つめからの ミスが 4つ たまると かげの こうげき（§4.3）。
5. 🔊 もう 一度 聞く・✎ かきじゅん（見ると こうげきが へる）・↺ やりなおし。

- **出る ことば**: その 話までに 書いた かなだけで できる ことば（濁点・小さい 字は 出さない。「ー」は はじめから うまって いる）。
  `src/data/kanaWords.ts` に 話ごとに ならべる（テストで「その 話までの かなだけ」を 確かめる）。
- **字の ふういん**（`seals.ts` と 同じ 考え）: かげは その 話の かなを お札に もつ。ぜんぶ 1回ずつ 書くまで たおれない。
- 0章の たたかいは レベル・なかま・漢字の ぶきを 使わない（0章は 町に 着く 前）。強さは ★（HP）と かなの ぶき だけ。

### 4.2 ボス

| | いつ | あいて | お札 |
| --- | --- | --- | --- |
| ひらがなの ボス | かな 5話の あと（夜の 滑走路） | ほしを たべた おおかげ | ひらがな 46字 ぜんぶ |
| カタカナの ボス | かな 10話の あと（さいごの 車両） | モジクイ（1章 2話の モジクイ と 同じ 者） | カタカナ 46字 ぜんぶ |

- 46字を **できるだけ 少ない ことばで** ぜんぶ 通る ように 出す（まだ 書いて いない 字が 多い ことばから）。を・ヲ は「ほんを よむ」「ヲ（めずらしい 字）」。
- HP の バーは 3本（3つの 段）。字が 16・15・15 ひらく ごとに 次の 段（どの 字でも よい）。ボスの お話は その 段で 1行ずつ。
- 46字は 五十音表で **はじめから ぜんぶ** 見せる（書いた 字が 金色に ひらく。お札が 17字 以上の とき）。
- ひらがなの ボスに 勝つと ★2 へ（3. と 同じ 演出）。カタカナの ボスの あとが 今の かな 10話の おわり（モジクイが 町へ にげる）。
- **ボスは 話と 話の 間に 入る**（2026-10-17）: ボスは その 話の おわりの お話の **あと** に 来るので、話の おわりは ボスの 前で 止める。
  - かな 5話は 夜の 滑走路で 星が もどって「でんしゃは あさ」まで。夜明けの 空港の 駅（「ここは カタカナの えき」）は ひらがなの ボスの おわりに。
    （それまでは 5話で 夜明けの 駅まで 行き、ボスで 夜の 滑走路に もどって いた）
  - かな 10話は モジクイが ちゃわんを かかえて 居すわる ところまで。モジクイが 町へ にげる・電車が ナニワタウンに 着く・「つぎは かんじ！」は
    カタカナの ボスの おわりに。ちゃわんに 名前は 入って いない（名前は 9話で もどった）。
    （それまでは 10話で モジクイが にげて 町に 着いた あと、ボスで モジクイが もどって きて また にげて いた）
  - ひらがなの ボスの **おわりの お話は ★2 の 絵**（勝った ときに ★2 に なって いる ので、演出を 見せない 2回目からも ★2）。
    はじめの お話と たたかいは ★1。`kanaBossCast(script, 'intro' | 'outro')`。
- 地図の ひらがな・カタカナの 一覧の さいごに 👑 ボス。カタカナの 一覧は ひらがなの ボスの あと（前に カタカナを 進めた セーブは そのまま）。

### 4.3 ミスタッチ前提の 数値（2026-10-15）

「ボスは日本人の私ですらミサイル持ちでもクリアできませんでした」「多少はミスタッチ前提でゲームバランスを作ることが大切」を うけて、
「ときどき まちがえる 手」で 勝てる ように 直した。

| | まえ | いま |
| --- | --- | --- |
| かなの 判定（leniency） | 1.8 | 2.2（ふ・な・や は 3） |
| ネクマックスの HP（★1 / ★2） | 60 / 80 | 80 / 100 |
| かげの がまん | 1字で ミス 3つ | 1字の はじめの ミスは 数えず、のこりが 4つ たまると |
| かげの こうげき（かな 1〜10話） | 12〜19 | 8〜13 |
| ボスの こうげき（ひらがな / カタカナ） | 12 / 14 | 10 / 12 |
| 1字の こうげき（ミス 0・1・2・3〜） | ×1.5・×1.1・×0.8 | ×1.5・×1.4・×1.0・×0.7（かきじゅんを 見たら ×1.0） |
| 回復 | なし | ミス なしの ことば 💚 HP の 6%・ボスの 段が 進むと 💚 40% |
| まけたら | もう 一度 はじめから | ▶ コンティニュー（HP ぜんかい・お札と あいての HP は そのまま、何回でも） |
| 同じ 画を 3回 まちがえたら | ヒント だけ | その 画を 通す（`forgiveAfter`、漢字の たたかいも 同じ） |

- 判定の 数値は hanzi-writer の 判定を そのまま 使い、ぶれた 手（wobble 55）で はかった: 1.8 では 1字 平均 0.46 ミス（ふ 5.1・な 2.9・や 1.6）、2.2 で 0.23。
- `playKanaFight`（`kanaBattle.ts`）が 画面と 同じ ルールで 1たたかいを さいごまで 進める。`kanaBattle.test.ts` が コンティニュー なしで 確かめる:
  「2字に 1回 まちがえる 手」は ボスに 95% 以上、「1字に 1回 まちがえる 手」は どの 話も 95% 以上・ボスに 80% 以上 勝つ。
  「1字に 3回 まちがえる 手」は ボスに 勝てない（書く 力は 要る）。
- 町の 漢字の たたかい（`BattleScene`）も 同じ 考え: 1回の 書きの はじめの ミスは 数えない（`countedSlip`）、3回で 画を 通す、
  まけたら コンティニュー（`continuesFor`: ふつうの 話 1回・まとめの ボス 2回・むずかしい／チュートリアル／むかしの 道は 0）。
  `battleBalance.test.ts` が どの 話・まとめの ボスも「1回に 1回 まちがえる 手」で 勝てる ことを 確かめる（1章8話: 0.24 → 0.86）。

## 5. かなの ぶき

- **作り方**: ぶきの 名前を かなで 書く。名前の かなが ぜんぶ 自分の もの（3回）なら、その 名前を 1回 書いて できあがり。
  - ひらがな: かさ（2話〜）・おの・つえ・かたな（3話〜）・はさみ・むち（4話〜）・やり・ゆみ（5話〜）
  - カタカナ: ナイフ（8話〜）・ヨーヨー・トマホーク（9話〜）・ハンマー・ランス・ミサイル（10話〜）
  - 名前が 長い ほど 強い（かな 1字 ＋5%）。ボスの あとで ふえる ものは ない（シンプルに）。
- **0章の たたかい だけで 使える**。1章からの 漢字の たたかい・たいせんでは 使わない（もちものでも「かなの たたかい だけ」と 出す）。
- **チュートリアル**（漢字やさんの はじめての 1本 と 同じ 形）: かな 2話の あと、ネクマックスが「かさ！ ぶき！」→ かなの かじや へ。
  カード 4まい（✍️ 名前を かく → ⚒️ ぶきに なる → ⚔️ かなの たたかいで つよく → 🙅 かんじの たたかいでは つかえない）→ 「かさ」を 書いて つくる → つける。
