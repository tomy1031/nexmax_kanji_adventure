## 2. 1回 ひく とき

参考の 8コマを、このアプリの 絵と きまりで 作る。どの 場面も「スキップ」で とばせる。

1. **ガチャ開始** — 夜の 町の 広場に ガチャの 機械（地図と 同じ 絵）。ネクマックスが ハンドルを 回し、機械が ゆれる。
2. **カプセル** — 下の 口から カプセルが ころがり 出る。カプセルの 色は レア度（★3 銀・★4 金・★5 虹）。★5 は 虹に ふるえて
   「★5 かくてい！」の 帯。カプセルが 2つに われる。
3. **字を 書く** — 中から お札が とび出し、まん中で 大きく なる。**書き順どおりに 字が 書かれて いく**（書く 練習と 同じ
   書き順 データ）。字は すみの 色で くっきり。光るのは まわり だけ（2026-10-02「漢字 自体が 光で 太字に 表示されるのは よくない」）。
   書き おわると 読みが 出る。
4. **光** — お札の うしろに キャラの かげ（シルエット）が うかぶ。光が はじける。
5. **キャラ登場** — 大きい 絵、うしろに 大きく その 字。★が 1つずつ、NEW!、名前、ひとこと（ふきだし）。タップで つぎへ。
6. **字の ことば** — まん中に 字、まわりに その 字を 使う ことばの お札が 3まい（読みつき）。「○○の 字で できる ことば」。
7. **ステータス ＋ 入手完了** — カード（絵・★・名前・字・ひとこと 紹介・わざ）と、下で ネクマックスが
   「あたらしい なかまが くわわったよ！」。OK。

- もう もって いる カード（きずな ＋1）は 4 の あと すぐ 7 へ（6 は とばす）。
- はじめての ガチャ（16 §3）も この 流れ。7 の あとに 今の「じゅんびで えらぶと…」の カード。

## 3. 10回 ひく とき

1. ガチャ開始は 同じ。カプセルが 10こ つぎつぎ ころがり 出て、2れつに ならぶ（色で レア度が わかる）。★5 が あれば 帯。
2. ぜんぶ いっしょに われて、カードが くばられる（うらがえし）。タップ／「ぜんぶ めくる」で めくる。
3. **★5 が めくれたら、1回の ときの 3〜5（字を 書く → かげ → 登場）**。今の ★5 カットインは これに かわる。
4. **10回の けっか** — 大きめの カード（4・4・2）。カードに キャラの 字の 玉、★、名前、NEW・ピックアップの 札。
   下に ネクマックス「すてきな なかまに 出会えたね！」と、OK・「もう 10回」（◆が たりる とき）。

## 4. 待機（ガチャの 画面）

- ピックアップの 絵の うしろに、★5 の キャラの 字を 大きく うすく。
- ネクマックスが「どんな なかまに 出会えるかな？」。

## 5. 正直さ・ルール

- 出る カードは ボタンを おした とき もう 決まって いる。演出は それを 見せる だけ。
- カプセルの 色 ＝ レア度（今の カードの うらと 同じ きまり）。かくし 演出（色が あとで 変わる など）は しない。
- 「へらす うごき」の 設定では、動きを 短く（書く 場面は 字を すぐ 出す）。
- CSS・SVG の filter は つかわない（iPhone）。かげは 絵を マスクに した 色の 板で 作る。
