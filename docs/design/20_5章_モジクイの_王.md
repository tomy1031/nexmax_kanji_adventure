# 20 5章「モジクイの 王」

とみさんの 指示（2026-10-10）「5章を作成して下さい。」

4章「町を 回る」は タワーの 上で 終わり、**モジクイの 王** の ひくい 声が「大モジクイ、かえりましょう。字の ない せかいへ……」と
大モジクイを 連れて 消えた。ハナ「みんなで 行きましょう！」→ つづく。5章は その「字の ない せかい」。

5章は **21〜25課、ユニット16〜20 の 55字**（`src/data/mojiRoute.ts` の 5章）。初級I（N5 編）の 最後の 章で、
08 §3.3 の 表では「21〜25課: と 思います／名詞修飾／とき／たら — モジクイの 王。『もし 字が なかったら…』 → ネクマックス ★4 へ」。

## 2. 舞台と 人

- **シズカタウン**（SHIZUKA TOWN）: 夜の 電車で 行く「字の ない せかい」の 町。王が 字を ぜんぶ 食べて、
  町は しずかで 色が うすい。人は 寝て いて、名前も 歌も きせつも ない。まん中の 丘に 王の しろ。
  色は 1〜4章と 同じ（深い 藍色の 夜、ランタンの 琥珀色）だが、あかりは ほとんど 消えて いる。
  実在の 地名・店・看板は 使わない。場面の 絵は `img/shizuka/`、id は `shizuka_*`。
  - しずか（8課）は やさしい 語で、「字が ない → 音も ない」が 町の 名前で 伝わる。字が 戻ると 歌が はじまる（10話）。
  - 5章は ずっと 夜。まとめの ボスの あと、この せかいに はじめて **朝** が 来る（「夜が 終わりました」）。
- **ソラ と ハナ**: 4章に つづいて 3人（ソラ・ハナ・ネクマックス）で 行く。絵は 2章・3章の もの。

## 3. すじ（困る → その 話の 字で とける → 次へ 進む 理由）

- **5-1 あめの えき**（降思寝終言）: 夜の 電車を 降りると 雨。だれも いない えき。えきちょうさんは 立った まま 寝て いて
  「夜は まだ 終わりません……」。ソラ「王さまは『字の ない せかいへ』と 言いました」、ネクマックス「ここは 字の ない せかいだと 思います」。
  まくらの モジクイ（💤 ねぼすけ）。書くと 雨が 降らなく なり、えきちょうさんが おきる。「王さまは『この 町の 字も ぜんぶ 食べます』と
  言いました。それから、みんな 寝ました」。王は 町の まん中の しろに いる。
- **5-2 かんじを しって いますか**（知動同漢字方）: 町の ひろば。からくり時計の 人形が 動かない。ふだは ぜんぶ くろくて 同じ。
  男の子「これは 何ですか？ ぜんぶ 同じでしょう？」「かんじ？ 知りません」。はんこの モジクイ（🔁 まねっこ）。
  書くと 人形が 動き、男の子「これが 漢字ですか！ 書き方を 知りたいです！」。ネクマックスが「字」の 書き方を 見せる。
  （字を 知らない 子に 教える — 王の 話の 前ぶれ）
- **5-3 わたしが すんで いる 町**（図館銀町住）: 町の まん中の みち。図書館と 銀行の ドアに 大きい かぎ。
  町長さん「わたしが 住んで いる 家は どこですか？」（家の 名前の ふだが ない）。かぎの モジクイ（🔐 ひとりじめ）。
  書くと 名前が 戻る。図書館の 本に 小さい モジクイの 絵 —「ずっと まえ、王さまは 小さい モジクイでした」。
- **5-4 あかい ふくを きて いる ひと**（度服着音楽持）: 音楽の ホール。がくふに 字が なく、何を ひくか わからない。
  どの 服が だれの ものかも わからない。みみせんの モジクイ（🙉 きかない）「しーっ！ しずかな 町が いちばん！」。
  書くと 音楽が 戻る。音楽の 人「これは わたしが いつも 着る 服です」。そとは 雪 — こうえんが ずっと 冬。
- **5-5 まっすぐ いくと**（春夏秋冬道堂）: こうえんの 四つの 木が ぜんぶ 冬の まま。にわの おじいさん
  「春の とき、ここは 花で きれいです」。ゆきだるまの モジクイ（❄️ つめたい）「ずっと 冬が いいです！」。
  書くと 春が 来る。「この 道を まっすぐ 行くと、食堂が あります」。でも 雪の 中に いた ソラが「はっくしょん！」。
- **5-6 ぐあいが わるい とき**（建病院体運乗）: 食堂の となりの 病院。くすりの ふだに 字が なく、エレベーターも 動かない。
  くしゃみの モジクイ（🤧 かぜひき）。書くと かんごしさん「エレベーターに 乗ると、お医者さんの へやへ 行きます」
  「体の ぐあいが 悪い とき は、すぐ 来て ください」。ソラ「体が 元気に なった！」
- **5-7 にいさんが くれた もの**（家内族兄弟）: 小さい 家。男の子 2人が「あなたは だれ？」— アルバムの 名前が 食べられ、
  きょうだいが おたがいを わすれた。アルバムの モジクイ（🫥 わすれっぽい）。書くと 名札が 戻り「にいさん！」「弟！」。
  弟「にいさんは いつも ぼくに 本を 読んで くれました」。父の 手紙「家内と 子どもたちへ」— ぼくたちは 家族だ。
- **5-8 とけいを なおして もらいました**（奥姉妹海計）: 海の ちかくの 時計の 店。大きい 時計に 字が なく 動かない。
  姉「妹が しろの 奥へ 行きました。『王さまと 話します』と 言いました」。なみの モジクイ（🌊 きぶんや）。
  書くと ネクマックスが 時計を なおし、姉「時計を なおして もらいました！」「この かいがらを 妹に あげて ください」。
- **5-9 まどを あけたら**（部屋室窓開閉）: しろの 中。部屋が たくさん、窓に くろい カーテン。ドアを おしても 動かない。
  カーテンの モジクイ（🙈 てれや）。書くと「窓を 開けたら、月の あかりが 入りました」。教室に 妹。
  妹「この 教室で、王さまは いつも ひとりでした」「王さまは 字が わかりません。だから 字を 食べました」。
- **5-10 もし じが なかったら**（歌意味天考）: しろの いちばん 上。天気は ずっと 悪い。大モジクイ（💜 王さまが 好き）
  「王さまの 部屋に 入らないで ください！」「王さまは 言いました。『もし 字が なかったら、みんな 同じです』」。
  書くと 町の 人が 歌を 歌い、天気が よく なる。大モジクイ「王さまは 小さい とき、字が わかりませんでした。だれも おしえて くれませんでした」。
- **5-11 まとめの ボス — モジクイの 王**: 王の 部屋。王「もし 字が なかったら、みんな 同じです。あなたは どう 思いますか？」
  — プレイヤーが こたえる（2つの えらぶ ボタン。どちらも 正解・不正解は ない）。55字から 苦手な 10字。
  勝つと 王は 小さく なり「わたしは 字が わかりませんでした。ずっと ひとりでした」。ネクマックス「わたしたちの ともだちも、
  はじめは 字が わかりませんでした。でも、毎日 書きました」。王は はじめての 字「友」を 書く。字の ない せかいに 字と 歌と **朝** が 戻る。
  その とき、プレイヤーが 書いた 220字の 光で ネクマックスの むねが ひかり、**★4 に クラスアップ**（08 §7.3 の クラスチェンジの お話）。
  さいごに 小さい かげが スマホの 中へ —（6章「ネットに 逃げた モジクイ」への つなぎ）。
