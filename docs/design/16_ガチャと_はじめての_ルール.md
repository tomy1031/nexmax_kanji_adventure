# 16 ガチャと はじめての ルール

とみさんの 指示（2026-10-05）:
「いろんな 星が あるのは 誤解や 混乱に 繋がりますか？ … それよりは ルールを 理解させる 工夫が 大事かも。
一つの 文字だけは 10回 書かせて チュートリアル用の 武器を 強制的に 作るとか、仲間も 最初の チケットを 渡して
ガチャを 引かせるとか。あと ガチャ演出が ワクワクしないし 動線が 目立たなすぎるので 要改善。
ガチャ%の 表示など 色々 必要な もの 考えて 取り組んで」

---

## 1. ★の 意味が 4つ ある こと（答え）

**結論: ★ は 1つに まとめなくて よい。** ゲームの ★ は 2種類に 分かれて いて、どちらも よく ある 形。

| 種類 | どこ | 見た目の きまり |
| --- | --- | --- |
| **ためる ★**（すすみ） | 字の ★1〜3、たたかいの ★★★ | 空(☆)が 金(★)に うまって いく。数が ふえる |
| **レア度の ★**（もとから） | なかまの ★3〜5、武器の ★1〜5 | いつも ぜんぶ うまって いる。色・わくで ちがいを 出す |

まぎれるのは、2つが **同じ 画面に ならぶ ところ** だけ（たたかいの 結果で「★★★」の すぐ 下に「字 ★2に なった」、
じゅんびで なかまの ★ と 字の ★）。ここは 文字で ラベルを つければ 足りる。★ そのものを かえる より、
**ルールを 手で 1回 やらせる**（§2・§3）ほうが ずっと 効く（とみさんの 考えの とおり）。

## 2. はじめての 武器（1章 2話の あと）

**before**: 1章 2話の お話で 山田さんが 漢字やさんを 見せ、ネクマックスが「火 ＋ 山 → 🌋」と 言う。でも この とき
★3 の 字は 1つも ない ので、漢字やさんは からっぽ。ルールは 4枚の カードで 読むだけ。

**after**: お話の すぐ あと、漢字やさんで **いっしょに 1回 作る**。
1. 「火を ★3 に しよう」→ 火の 書く 練習（★3 まで。1話・2話で 書いた 分は 数える、あと 5回ほど）。
2. 「山も ★3 に しよう」→ 同じ。
3. 漢字やさんで 火 → 山 の じゅんに えらぶ（ほかの 字は うすく、ゆびで さす）→ つくる（すみは いらない）。
4. **火山（かざん）** が できる → そうび。「本当に ある 言葉は 強い」「じゅんばんが 大事（山火は 弱い）」を ここで 言う。
5. 地図へ（1章 3話が NEW）。

- 1回だけ（`tutorials.firstWeapon`）。とちゅうで やめても、つぎに 漢字やさんを ひらくと つづきから。
- 火山は かくし武器では ない（1話の かくし武器は 日月、2話は 金山）ので、さがす たのしみは そのまま。

## 3. はじめての ガチャ（1章 4話の あと）

**before**: 4話の お話で「ジェムで、ほかの なかまを よびます！」と 言うだけ。ジェムは まだ 少なく、地図の 小さい
「なかま」の 札に 気づかないと ガチャを 知らない まま。

**after**:
1. 4話を はじめて クリアすると **ガチャチケット 1まい**（`gachaTickets`）。
2. お話の あと ガチャへ。「チケットで 1回 ひいて みよう！」と ゆびで さす。
3. はじめての 1回は **★4 いじょう かくてい**（会った 人の 中から。すぐ たたかいで つかえる）。
4. 出た なかまの わざと「じゅんびで えらぶと たたかいで わざを つかう」を 1行。→ 地図へ（1章 5話が NEW）。

- チケットは 1回 ひく（◆100 と 同じ）。どの ガチャでも つかえる。天井の 数にも 入る。

## 4. ガチャの 動線

**before**: 地図の 左の 小さい 札「🤖 なかま」だけ。下の タブにも ない。

**after**:
- 地図の 右に **大きい ガチャの 機械**（絵）。ゆっくり ゆれて 光る。
- 赤い 札で 今 ひけるか を 出す: 「チケット 1」「1回 ひける」「10回 ひける」。ひけない ときは ◆ あと いくつ。
- 左の 小さい「なかま」の 札は なくす（同じ ものが 2つ ならばない）。

## 5. ガチャの 演出

**before**: ボタンを おすと 0.45秒 まって、カードが うらがえしで ならぶ。めくると 小さい 音。

**after**（正直さは そのまま: 光の 色で レア度が 先に わかる。出る ものは ひいた とき もう 決まって いる）:
1. 暗く なって **魔法陣**（絵）が ひかる。光の 玉が 1つ（10回なら 10こ）おりて くる。玉の 色は いちばん 高い レア度
   （★5 虹・★4 金・★3 銀）。
2. 光が はじけて カードへ。
3. 1回: 大きく 1枚。★が 1つずつ ポンと つき、絵・名前・「NEW!」の はんこ・ひとこと。
   10回: 10枚 くばられ、タップで めくる（「ぜんぶ めくる」）。★4 は 金、★5 は 虹に ふるえて から めくれる。
4. **★5 は 全面の カットイン**（大きい 絵・虹の 光・ひとこと・ファンファーレ）。
5. いつでも「スキップ」。

## 6. かくりつ の 表示

いまの 表示（★ごとの %・天井・きずな）に 足す:
- **くわしい かくりつ**: ボタンで ひらく 表。カード 1枚ずつの %（ピックアップは 半分ずつ）。会って いない 町の 人は 入らない。
- **天井の バー**: 10回 ボタンの 下に「★5 かくてい まで あと N回」と バー（いつもの・ピックアップ）。
- お金は つかわない こと・ジェムは 書くと もらえる ことは そのまま。

## 7. PR の 分け方

1. 設計書（これ）と 絵（機械・魔法陣・チケット）
2. 地図の ガチャの 入口（§4）
3. かくりつ の 表示（§6）
4. ガチャの 演出（§5）
5. はじめての ガチャ（§3）
6. はじめての 武器（§2）
