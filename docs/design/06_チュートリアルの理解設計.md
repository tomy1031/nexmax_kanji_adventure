# 06 チュートリアルの理解設計

対象: ゲームの最初の15分（タイトル → 最初の戦闘 → 合成が開くまで）。
物差し: NexmaxAcademy `docs/design/01_理解設計ガイド.md`（13原則）と
`docs/design/05_ゲーム導入オンボーディング設計.md` §0 の「作る前の3行」。

## 0. 作る前の3行

1. **前提**（学習者がすでに持っているもの）
   スマホゲームの「お話 → 操作を覚える → 戦う」の順番は母語のように読める。
   漢字は1年見ている。**ただし「指でなぞって書く」UIは初めての可能性が高い。**
2. **新情報**（この15分で入れる新概念は **1つだけ**）
   **「漢字を書くと、力になる」。**
   合成・属性・すみ・ガチャ・個体・対戦・ことば図鑑は、**ここでは1つも出さない**。
3. **つまずき予測**（と、それぞれの手当て）

| つまずき | いつ起きるか | 手当て |
| --- | --- | --- |
| どこを なぞるのか 分からない | 最初の1字 | 手本を敷き、**書き順アニメを自動で1回 流してから**始める |
| なぞっても 反応しない（線が細い・速い） | 最初の1字 | `leniency 1.15` は既に入れてある。加えて2回まちがえると 正しい線が光る（hanzi-writer の `showHintAfterMisses: 2`） |
| なぜ 書くのか 分からない | お話のあと | **お話の中で「字が力になる」を先に見せる**（§2） |
| 10回が 終わらない | 2字目以降 | 戦闘に要るのは **3字**。残りは あとでよい（§3） |
| 戦闘で 何を書くか 分からない | 最初の戦闘 | **最初の戦闘だけ 漢字を見せる**。2回目から 読みと意味だけにする |
| 一度に 覚えることが 多い | クリア後 | 仕組みは **1ステージに1つずつ** 開く（§4） |

## 1. いまの何が問題か（測った数字）

```
ステージ1「田んぼの村」
  お話の行数              11
  漢字                    9 字
  最初の戦闘までの書取り    90 回   ← 1回15秒として 23分
  クリアで開くもの          合成 / ことば図鑑 / ガチャ / 図鑑 / デイリー / 対戦 = 6
```

3つ、はっきり外している。

1. **23分 なぞってからでないと 戦闘に届かない。** 「書くと力になる」を体で分かる前に、
   ただの書写が23分続く。ここで離れる。
2. **クリアした瞬間に 6つの仕組みが同時に開く。** AGENTS.md 規律10「1ステージに 枠組みは 1つ」に
   真正面から反している。
3. **役割が渡されていない**（P1）。お話は村を描くが、「あなたはネクマックスで、
   **書くのはあなた**」と言っていない。学習者は第三者のまま書き始める。

さらに、**この game の 一番いい 仕掛けを 使っていない**。
むかし編の答え——枝の無い大木を「村で覚えた字をきざんで」登る——は **8話**にある。
チュートリアルが 一番 必要としている 理屈が、8話まで 出てこない。

## 2. 直しかた その1 — 物語で「字が力になる」を先に見せる（P1・P2・P9）

### P9 が 一番 効く

> **P9. ゲームの仕組みそのものを教訓にする。**
> ルール自体が法則のメタファーになっていれば、遊ぶこと＝法則を体感すること。
> アンチパターン: 学習内容と無関係なミニゲーム。

このゲームの法則は **「書ける字の数だけ、先へ行ける」**。
8話の大木は その法則の 完成形。**チュートリアルには その 小さい版を 置く。**

### 新しい 0話「はじめの 一歩(いっぽ)」

タイトルから「はじめる」を押すと、1話ではなく **0話** に入る。3〜4分で終わる。

```
お話 4行
  村の 入口に 大きな 石。ネクマックスは 通れない。
  ハナ「字(じ)を 書(か)くと、力(ちから)に なるよ。」
  ハナ「ためして みて。」
↓
書取り  「一」だけ・3回          ← 10回ではない
  1回目: 書き順アニメが 自動で 流れる → 手本の上を なぞる
  2回目: 手本あり
  3回目: 手本なし
↓
その場で 石が 割れる
  「一(いち)」の 線が 石に 走って、石が 二つに 割れる
  ネクマックス「……書(か)けた！ 道(みち)が できた！」
↓
1行だけ 説明
  「同(おな)じ 字(じ)を 10回(かい) 書(か)くと、その字は じぶんの ものに なる。」
↓
0話 おわり → 1話へ
```

- **新概念は1つだけ**: 書く → 力になる。合成もガチャも 名前すら 出さない。
- **P1（役割）**: 2行目で ハナが「ためして みて」と **学習者に** 言う。
  石を割るのは ネクマックスではなく **書いた人**。
- **P2（開く箱）**: 石が 箱。**開ける鍵が 学習行為そのもの**。
  情報を読んで進むのではなく、書いた結果として 道が開く。
- **P6（階段）**: なぞる（手本あり）→ なぞる（手本あり）→ **書く（手本なし）** の3段。
  いきなり手本なしにしない。最後は必ず産出で終わる。
- 「一」を選ぶ理由: **1画**。なぞり書きのUIを 覚えるためだけの字なので、
  字の難しさを ここで 足さない。

## 3. 直しかた その2 — 戦闘に要る字を 3字にする

**10回の決まりは 変えない**（ユーザー指定）。変えるのは
「ステージの字を **全部** 10回書かないと 戦闘に行けない」という こちらが 勝手に足した縛り。

| | before | after |
| --- | --- | --- |
| 戦闘に行くのに要る字 | 9字 ぜんぶ（90回） | **3字**（30回） |
| 残り6字 | 同じ場所で 続けて書く | いつでも書ける。書いた分だけ 戦闘が 楽になる |
| 最初の戦闘まで | 約23分 | **約8分** |

- 戦闘で出る字は **手に入れた字だけ**。3字しか持っていなければ その3字が回る。
- 「あと6字 書くと つよくなる」を 戦闘前の画面に出す。**急かさない。選べるようにする。**
- P11（レベル差は同じ教材の別モード）: 速い学習者は 9字ぜんぶ書いてから行く。
  遅い学習者は 3字で行って 勝つ。**同じステージのまま 負荷を 学習者が握る。**

## 4. 直しかた その3 — 仕組みは 1ステージに 1つずつ開く

AGENTS.md 規律10「1ステージに 枠組みは 1つ」の実装。

### ステージの並び before → after

**before**

| # | ステージ | 開くもの |
| --- | --- | --- |
| 1 | 田んぼの村 | **合成・ことば図鑑・ガチャ・図鑑・デイリー・対戦（6つ同時）** |
| 2〜10 | … | （もう 開くものが ない） |

**after**

| # | ステージ | この話で 入れる 新概念 | クリアで 開くもの |
| --- | --- | --- | --- |
| **0** | **はじめの一歩**（新） | **書くと 力になる** | 1話 |
| 1 | 田んぼの村 | 10回で 字が じぶんのものになる／戦闘 | **合成** |
| 2 | 村のやまい | 字を 2つ あわせると 武器になる | **ことば図鑑** |
| 3 | 山へ行く | 作れる言葉を 探す（すみ） | **デイリー** |
| 4 | イノシシと大きなハチ | 属性の 相性 | **ガチャ**（ジェムが 貯まる頃） |
| 5 | 光の入り口 | 個体を 入れ替える | **図鑑** |
| 6 | また歩き出す | 復習・さび | — |
| 7 | 登れない木 | （物語の 山） | — |
| 8 | 字をきざむ | **法則の 回収**（0話の石＝この大木） | **対戦** |
| 9 | 雲の上 | — | — |
| 10 | 生命草 | — | — |

並びの理由（「足した順」ではなく「前提が揃う順」）:

- **合成は1話のあと。** 字を9つ持っていないと 合成する物が無い。
- **ことば図鑑は2話のあと。** 合成を1回もしていない人に「作れる語の一覧」を見せても、
  何の一覧か分からない。
- **デイリーは3話のあと。** すみ／ジェムを 使う場所を 知ってから でないと、
  もらっても 意味が 分からない。
- **ガチャは4話のあと。** デイリーが開いた翌日には ジェムが貯まる。
  開けた瞬間に 1回も回せない ガチャは 開かないのと同じ。
- **対戦は8話のあと。** 8話で「書ける字の数だけ 先へ行ける」が 物語で 完成する。
  対戦は その法則を 人と 競う形。**順番が 意味を持つ。**

> 8話は 0話の 回収でもある。石を割った小さな話が、大木を登る大きな話になって返ってくる。
> 0話を入れる 本当の理由は そこ。チュートリアルを 物語の 外に 置かない。

## 5. 文言（P8: フィードバックは「次の行動」）

0話で使う文言。**判定はぼかさない。ぼかさずに 次の行動を 添える**（絶対規律1）。

| 場面 | 文言 |
| --- | --- |
| 1回目の前 | 「書(か)きじゅんを 見(み)てね。」（アニメが流れる） |
| なぞれた | 「そう！ その 向(む)き。」 |
| 2回 まちがえた | 「line が 光(ひか)ります。そこを なぞって。」 |
| 3回 書けた | 「**書(か)けた。** 石(いし)が 割(わ)れるよ。」 |
| 石が割れたあと | 「**字(じ)は 力(ちから)。** 書(か)ける 字(じ)が ふえると、行(い)ける ところが ふえる。」 |
| 0話のおわり | 「同(おな)じ 字(じ)を 10回(かい) 書(か)くと、その字は じぶんの ものに なる。つぎの 話(はなし)で やってみよう。」 |

- 「がんばったね」で流さない。**書けた／まだ** を はっきり言う。
- 石が割れる演出は **結果の 可視化**であって ご褒美ではない。
  書いた字の 線が そのまま 石の 割れ目に なる（P9: 仕組みが 教訓）。

## 8. 2026-09-23 の やり直し — 0話で「一の太刀」を作り、戦う

とみさんの指定: **「チュートリアルで 一を 手に入れたときに、その漢字を使って 一の太刀を 作れるように。
その後に 会話を少し すすめて、敵が現れるので、戦いが 始まるように」**。
あわせて、書取りは **「書いた字が 刃のように 岩を 斬りつけ、書ききると 岩が 割れて、
中から 漢字の マテリアルが 手に入る」** 形にする。

§0 の「0話で 入れる 新概念は 1つだけ」は、この指定で **上書きした**。
ただし「説明を 先に 並べない」は 守る。新しい ことは **1つずつ、その場で 1回 やってから** 次を 出す。

### 並び before → after

**before**（§2）

```
お話 4行 → 「一」3回（石に 書く）→ 石が 割れる → お話 3行 → 1話へ
```

**after**

```
お話 5行   村の 入口に 石。ハナ「書いた 字は 刀のように 石を 切る」「10回 書くと あなたの ものに なる」
  ↓
書取り     「一」10回。1回 書くごとに 岩が 1つ 割れ、かけらが 1つ 出る（10こで 一を 入手）
  ↓
お話 4行   道が ひらいた。ハナ「手に 入れた 字は 武器にも なる」
  ↓
れんせい   「一」＋ 刀の かた → 一(いち)の 太刀(たち)（そうびする）
  ↓
お話 5行   いたずらガラスが 来る。ハナ「一を 書いて。書けた 字が こうげきに なる」
  ↓
戦い       「一」を 書いて こうげき（最初の 戦いだけ 字を 見せる）。カラスは にげて いく
  ↓
お話 4行   「書ける 字が ふえると、もっと 強い 武器が 作れる」→ 1話へ
```

並びの理由（前提が 揃う順）:

- **10回を 先に 言う。** 書く前に「10回で じぶんの ものに なる」と 知っていれば、
  かけらが 1つずつ 集まる 画面を 見て 数えられる。後から 言うと 10回は ただの 作業に なる。
- **太刀は 入手の 直後。** 「手に 入れた 字は 武器に なる」は、字を 持った 瞬間でないと 意味が 無い。
- **戦いは 太刀の 直後。** 作った 武器を すぐ 使う。使わない 武器は 覚えない。
- **太刀は 1字で 作る 特別な 武器**（`forgeSingleBlade`）。★1・攻撃は 最低。ふつうの 合成（2〜3字）は
  そのまま 1話の あとに 開く。**0話で 合成の 画面・ルールは 出さない**（合成という 語も 台本に 出さない。テストで 固定）。
- **10回の 決まりは 変えていない。** 「一」は 1画なので 10回でも 1分 かからない。

### 書取りの 見せかた（岩を 斬る）

| 学習の できごと | 画面で 起きること |
| --- | --- |
| 1画 正しく 書けた | 線が 刃に なって 岩を 走る。光る 切りあとが 残り、岩が ゆれる |
| 1画 まちがえた | 岩に はじかれる（小さく ゆれるだけ。切りあとは 残らない） |
| 1字 書けた（まちがい 2回まで） | 岩が 2つに 割れ、中から その字の かけらが 出て 下の 10マスへ 入る |
| 1字 書けた が 3回 以上 まちがえた | **岩は 割れない**。「まだ 正かいでは ない」と はっきり 言い、同じ 岩で もう一度 |
| 10こ 集まった | 「10こ 集まった！」→ その字の カード。「手に 入れた」 |

- 判定を ぼかさない（「正かい」「まだ 正かいでは ない」＋ まちがえた 数）。
- 割れる／割れないは **結果の 可視化**で あって ご褒美の 演出では ない（§5 と 同じ 考え）。

### ステージの 入りかた（同日の 指定）

ステージ選択で **「漢字(かんじ)れんしゅう」** と **「ストーリー（バトル）」** を えらべる。

| | 中身 |
| --- | --- |
| 漢字れんしゅう | そのステージの 字を 1つ えらんで 岩を 斬る。お話・戦いは 無い |
| ストーリー（バトル） | 絵本の お話 → 相手が 現れる → 戦い。戦いは **持っている 字**で 行う。持っている 字が 3つ 未満なら、その ことを はっきり 言い、れんしゅうへの ボタンを 出す |
