# 11 なかまが 効く・ガチャの 種類・コンボの 気持ちよさ・武器を ロボットに 積む

とみさんの 指示（2026-10-03）:

> - 仲間が 効いて いない。いる 意味が 伝わらないし、サポート手段が 薄い

05（やりこみ）§2.4 きずな・§3 ガチャ、08（新ルート）§6.6 コンボと 必殺技・§7.2 パーツ・§8 なかま を、

## 2. コンボの 演出（#1）

**ねらい**: 「一発で 書けた」が 続くほど、画面が どんどん 盛り上がる。止まったら 分かる。

| | いま | 新 |
| --- | --- | --- |
| 画を 1本 書く | ネオンの 音 1つ | 音の 高さが **コンボと 画の 順で 上がる**。書いた 線の 終わりに 小さな 火花 |
| 1字 書き終わる | 光が 飛ぶ・数字 | ＋ コンボ数が **はねて 大きく なる**。色が 白 → 金 → だいだい → 虹 と 変わる |
| 3・5・7・10 コンボ | なし | 帯が 横切る「いい ちょうし！」「ノリノリ！」「とまらない！」「さいこう！」＋ 上がって いく 音 |
| 3コンボ 以上 | なし | 画面の ふちが コンボの 色で ゆっくり 光る。飛ぶ 光の 玉が 大きく なる |
| 止まった | 小さな 文字が 消える | コンボの 数字が くずれて 落ちる・低い 音・「コンボ ストップ」 |

- 補正（+10%／コンボ、最大 +50%）は 今の まま。数字だけ 見せて 計算と ずらさない。
- `reducedMotion` の ときは 動きを 止め、数字と 色だけ 変える。
- 書いた 字の 上には 光を 重ねない（`docs/constraints.md`）。CSS/SVG の filter は 使わない（iPhone）。

## 3. なかまが 戦いに 出る（#2）

### 3.1 見える・しゃべる

- 戦いの 画面で、ネクマックスの 横（甲板の 左）に **なかまの 立ち絵**（小）。いつも 少し ゆれて いる。
- **ひとこと**（ふきだし 1.6秒）: 戦いの はじめ・3コンボ・ネクマックスが こうげきを 受けた とき・わざ・勝った とき。
  なかま ごとに 性格に 合わせて 書く（N5・ふりがな）。
- 得意な 武器で 書いた ときは 数字の 横に「とくい！ +20%」。なかまの 力が **目に 見える**。

### 3.2 わざ（サポート）

**わざゲージ**: 一発で 書くと ＋2、1回 まちがいで ＋1。**6 で 満タン**（一発 3字）。
満タンに なると なかまが 光り、「わざ」ボタンが 出る。押すと カットイン（立ち絵が 横から 入り、わざの 名前）→ 効く。
**むずかしい（Hard）でも わざは 使える。ただし 満タンは 9**（`skillGaugeFull(difficulty)`: normal 6／hard 9。
Hard は 書く 約10回なので 1試合に 約2回。敵の HP・こうげきの 式は わざを 数えない — もう一方の セッションと 決めた、2026-10-03）。

| わざの 種類 | 効き目（★3 / ★4 / ★5） | 合う 性格 |
| --- | --- | --- |
| いやし | HP を 回復 25 / 35 / 50 | おせわ・みまもり・おもいやり |
| まもり | 敵の つぎの こうげきを 0 に（★5 は 2回） | まじめ・どうぐ・まとめ |
| おちつき | 敵の いかり（ミスの 目もり）を 2 / 3 / ぜんぶ もどす | ゆめ・なぜなぜ・デザイン |
| ヒント | つぎの 字の 書きじゅんを 見ても こうげきが へらず、ミスにも 数えない（★5 は 2字） | あんない・よそう |
| ちから | つぎの 1字の こうげき ×1.5 / ×1.8 / ×2.2 | スタート・もりあげ・アイデア |
| コンボ | コンボ ＋2、つぎの 2字は まちがえても コンボが 切れない（★5 は 3字） | わくわく・おうえん |

- **学習が 主**: わざは「書く」ことで たまる。わざで 書く 回数が 減る ことは ない（敵の HP を 直接 削る わざは 作らない）。
- 1回の 戦いで 何度でも（ゲージが たまれば）。ゲージは 戦いを 出ると 0。
- 得意な 武器の 補正（+15〜35%）と 苦手属性 半分は 残す。

### 3.3 じゅんびで 選ぶ

- じゅんび（`MojiEpisodeScreen` の ReadyScreen）に **なかまの わく**: 立ち絵・名前・わざ・得意な 武器。
  押すと なかまの 一覧（持って いる カードだけ）→ 選ぶ。ボスの 属性に 強い なかまには「おすすめ」。

## 4. なかまの データ（#3）

### 4.1 キャラ と カード

- **キャラ**: だれか（名前・性格・わざの 種類・得意な 武器・苦手属性 半分）。
- **カード**: キャラ × レアリティ（★3・★4・★5）。**同じ キャラでも ★ が 違えば 絵と 強さが 違う**。
  - ★3: 今の 絵（ロボットは 今の 16体）。
  - ★4: 衣装ちがい（例: 「はっぴの もりあげ」）。わざが 1段 強い・ひとことが 1つ 多い。
  - ★5: 特別な 姿（例: 「ネオンの あんない」）。わざが 2段 強い・カットインが 金。

| | キャラ | ★3 | ★4 | ★5 |
| --- | --- | --- | --- | --- |
| ネクマックスの なかま（ロボット） | 16 | 16 | 16 | 6 |
| 町の なかま（人） | 6（リンさん・山田さん・先生・医者・パン屋・駅員 の 案） | 6 | 6 | 2 |
| 合計 カード | 22 キャラ | 22 | 22 | 8 → **52枚** |

- 物語で もらう なかま（1章 4話の 七ばん＝まじめ）は ★3。ガチャの ★4・★5 で 同じ キャラの 上の 姿が 手に 入る。
- 新ルートだけで 遊ぶ 人が 手に 入らない キャラを なくす（今は みまもり・スタートが むかし編だけ）→ ガチャに 入れる。

### 4.2 きずな（限界突破）

- 同じ **カード** が 出ると きずな ＋1（Lv0〜5）。Lv ごとに わざの 効き目 ＋8%。Lv5 の あとは ◆ に かわる（★3 ◆20・★4 ◆60・★5 ◆200）。
- 一発で 書き切って（★3 クリア）勝つと、連れて いた なかまの きずな 点 ＋1（1日1回）。

### 4.3 セーブの 移し替え

`individuals: string[]` と `activeIndividual` を `cards: Record<カードid, { bond }>` と `activeCard` に 移す。
今 持って いる なかまは、その キャラの ★3 カードに なる。きずな 0。
Hard の `loadoutFromSave`（`lib/difficulty.ts`）も `activeCard` の キャラを 読む ように 同じ PR で 直す。

## 5. ガチャの 種類と 演出（#4）

### 5.1 3つの ガチャ

| ガチャ | 出る もの | 1回 / 10連 | 特ちょう |
| --- | --- | --- | --- |
| **いつもの** | ぜんぶの カード | ◆100 / ◆900 | ★5 3%・★4 17%・★3 80% |
| **ピックアップ**（週がわり） | ぜんぶ。ただし 今週の ★5 1枚・★4 2枚が 出やすい | ◆100 / ◆900 | ★5 が 出たら 半分は 今週の ★5 |
| **町の ガチャ** | 町の なかま だけ（人） | ◆60 / ◆540 | ★5 なし。★4 25% |

- 天井（短く かたく — `lib/gacha.ts` の 方針の まま）: **10連は ★4 以上 1枚 かならず**。**★5 は 30回で かならず**（ガチャごとに 数える）。
- お金は つかわない。ジェムは 学習でしか 入らない（今の まま）。
- 確率と 天井は 画面に いつも 出す。ハズレを 当たりに 見せる 演出は しない（05 §3.3）。

### 5.2 演出

- 封筒の **ふちの 色で ★ が めくる 前に 分かる**（★3 銀・★4 金・★5 虹）。
- めくると 立ち絵が 出て **その なかまが ひとこと**。★5 は 0.8秒 ためて 大きく めくる。
- 音: めくる・★4 の 鐘・★5 の ファンファーレ。ガチャ画面に BGM（shop）。

## 6. 武器を ロボットに 積む（#5）

- 新ルートの 戦いで、ネクマックスの **背中・肩に 武器を 積む**（8つの 形 それぞれの 絵）。
  書き終わると 武器が 前に 出て、そこから 光が 飛ぶ。筆は 手に 持った まま（字は 筆で 書く）。
- 見た目は ★ と 強化で 変わる:

| | 見た目 |
| --- | --- |
| ★1〜2 | 銀の 武器 |
| ★3〜4 | 属性の 色の 光（うしろに 丸い 光） |
| ★5 | 金の 武器 |
| 強化 Lv1〜5 | ⚒ の 数・Lv3 で 光の 輪・Lv5 で 輪が 金、名前に「・極」 |

- 強化 Lv は レシピに 持たせ、「レシピ → 武器」を 1つの 関数に まとめる（戦いの 武器と Hard の `loadoutFromSave` が 同じ 関数を 使い、Hard が 自動で そろう）。
- **強化**（05 §2.2 の「鍛える」を 簡単に）: 図鑑・もちものの 武器から「強化」。その 武器の 字を、読みだけ 見て 書く。
  一発で 書けた 字ごとに 強化点 ＋1。1つの 武器は 1日1回。Lv1〜5 で こうげき ＋6%／Lv。**書いて 強く する**。
- もちもの（そうび画面）では ネクマックスの 絵に 武器・盾が 積まれた 形で 見える。
- 絵: 8つの 形 × （ふつう・金）＝ 16枚。Codex で 作る（台帳 `scripts/art/manifest.mjs` に 足す）。

## 7. たいせんで 効く（#6）

| | いま | 新 |

## 8. 町の 人を 描き直す（#7）

- 31人を **人間**（と 一部は 動物・小さな ロボット）の 絵に。今の 立ち絵の 服・持ち物・役は 残す。
  ネクマックスと なかま（ロボット）と 見分けが つく ことが 目的。
- 絵の きまり: 今の ナニワタウンの 絵と 同じ 塗り（台帳 `BG_NANIWA`・`FOLK_PAINTED` の 調子）、白い 背景で 切り抜く。
- 町の なかま 6人は、この 絵を ★3 に 使い、★4・★5 は 衣装・場面ちがいを 足す。
