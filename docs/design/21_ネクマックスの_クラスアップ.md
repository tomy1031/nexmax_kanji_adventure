# 21 ネクマックスの クラスアップ ★4

5章「モジクイの 王」（docs/design/20、PR #221）は、まとめの ボスの お話で ネクマックスが ★4 に なって 終わる
（立ち絵 `img/chara/naniwa/nexmax_star4.webp`、`naniwaCast.ts` の `nexmax:star4`）。でも しくみは 何も かわって いない。
ここでは 08 §7.3「クラスアップ（★3 → ★4 → ★5）」の ★4 を しくみに する。

## 0. 作る前の 3行

- **いつ**: 5章の まとめの ボス（`moji-5-boss`）に 勝ったら ★4。どの むずかしさでも。もどらない。
- **何が かわる**: 地図・もちもの・じゅんび・たたかいの ネクマックスが ★4 の 姿に。アクセサリを 2つ つける（わく ＋1）。
- **どう 見せる**: レベルの 板と もちものに「クラス ★4」。なった ときに 1回だけ「★4 クラスアップ！」の カード。

## 1. 並び before → after

**before**

| | ★4 の お話の あと |
| --- | --- |
| お話 | 5章 まとめの ボスの おわりで「ネクマックスが ★4に なりました！」（絵 `nexmax_star4`） |
| 地図・もちもの | `nexmax_travel`（★3 の まま） |
| じゅんび（VS） | `nexmax_determined` |
| たたかい | `nexmax_brush` |
| そうび | 武器・盾・からだ・アクセサリ の 4つ |
| クラスの 表示 | なし（「★」は 字の ★1〜3 と なかまの ★3〜5 だけ） |

**after**（前提が そろう 順）

1. **クラスを きめる**（`src/lib/nexmaxClass.ts`）: `classOf(clearedStages)` → 3 か 4。★4 の 条件は `moji-5-boss` の クリア 1つ。
2. **アクセサリの わく ＋1**（`equippedGear.charm2`）: ★4 から つけられる。強さの 計算（たたかい・ハード・もちもの）は
   `wornGear()` 1つで 「★4 でなければ 2つ目は 数えない」。
3. **見た目**: ★4 なら 地図・もちもの は `nexmax_travel_star4`、じゅんびの VS は `nexmax_star4`、たたかいは
   `nexmax_brush_star4`、「いける！」などの よろこぶ ひとこと（`NexmaxSays` の cheer）は `nexmax_star4`。
4. **表示**: じゅんびの レベルの 板の 左に クラスの バッジ（★3 / ★4）。タップで クラスの カード（★3・★4・★5 で 何が かわるか）。
   もちものの ステータスにも「クラス ★4」。
5. **★4 に なった とき**: 5章の まとめの ボスの お話の あと（つづく の 画面）と 地図で、1回だけ「★4 クラスアップ！」の カード。
   「もちものを 見る」で アクセサリの 2つ目の わくへ。

## 2. いつ ★4 に なるか（条件）

- **`moji-5-boss`（5章 まとめの ボス）を クリアした こと だけ**。やさしい・ふつう・ハード の どれで 勝っても よい。
- 08 §7.3 の 案は「レベル ＋ まとめの ボスを 倒す ＋ 持って いる 字の 数」。この ルートでは、ボスに 着いた ときに 残りの 2つは もう そろって いる:
  - 各話は たたかいの 前に その 話の 字を ぜんぶ ★1 まで 書く（`MojiEpisodeScreen` の queue）。まとめの ボスは その 章の 字を ぜんぶ 習って、
    さいごの 話を クリアするまで ひらかない（`isFinaleOpen`）。だから 5章の ボスの 前に 1〜5章の **220字** が ぜんぶ 手に 入って いる
    （お話の「あなたが 書いた 220字の ちからで」と 同じ 数。テストで 確かめる）。
  - レベルの 上限は 持って いる 字で きまる（`levelCap` = 1 ＋ 字 ÷ 3）。字を 覚えないと 上がらない ことは もう 決まって いる。
  - 条件を 3つ 書くと、どれが 足りないかを 見せる 画面が 要る。シンプルに 1つに する。
- **お話と しくみを 合わせる**: お話では どの むずかしさでも ★4 に なる ので、しくみも 同じ。
- **下がらない**: クリアは 消えない。★4 は ずっと ★4。
- ★5 は 10章の まとめの ボス（08 §7.3「初級II 修了」、`mojiRoute.ts` 10章の あらすじ「ネクマックスが ★5へ」）。10章は まだ ない ので、
  クラスの カードには「つづきは じゅんび中」と 出す。

## 3. 何が かわるか

### 3.1 見た目

| 画面 | ★3 | ★4 |
| --- | --- | --- |
| ステージせんたく（地図） | `img/stageselect/nexmax_travel.webp` | `img/stageselect/nexmax_travel_star4.webp`（Codex、同じ ポーズ） |
| もちもの（そうびを 着せた 姿） | 同上 | 同上 |
| じゅんびの VS | `img/chara/naniwa/nexmax_determined.webp` | `img/chara/naniwa/nexmax_star4.webp`（お話の 絵） |
| たたかい | `img/battle/nexmax_brush.webp` | `img/battle/nexmax_brush_star4.webp`（Codex、同じ ポーズ） |
| ひとこと（`NexmaxSays` の cheer: いける！ など） | `nexmax_smile` | `nexmax_star4` |

- 新しい 2枚は もとの 絵と **同じ ポーズ・同じ 枠**。`scripts/art/import.mjs` の `matchFrame` が、切り抜いた 絵を もとの 絵の
  大きさ（600×800・520×780）と 位置に 合わせて 置く。だから そうびを 着せる 位置（`gearLayout.ts` の `LAYOUT_BATTLE`・`LAYOUT_TRAVEL`）は そのまま。
- お話の 中の 立ち絵（smile・think・guide…）と、ガチャ・書き取りの 小さい ひとこと（guide・think など）は 今の まま。
  ★4 の 表情ちがいは、★4 の ネクマックスが お話に 出る 6章を 作る ときに 足す。
- 武器の 位置（`WeaponMount`）も そのまま（背中に つむ）。

### 3.2 アクセサリの わく ＋1（08 §7.3「パーツの 枠 ＋1」）

- 08 §7.2 の パーツ（右うで・左うで・あたま・コア・あし）は まだ ない。今の わくは 武器・盾・からだ・アクセサリ の 4つ。
  ここに **アクセサリを もう 1つ**（`equippedGear.charm2`）。
- アクセサリに した わけ:
  - アクセサリは 38こ（1話に 1つ）あって、型（がまん・こうげき・HP・ぼうぎょ）が 分かれて いる。2つ えらぶと 組み合わせを 考える 楽しみが ふえる。
  - 武器・盾・からだは 漢字やさんで 作る もの（合成）。2つに すると「いちばん いい 1つを 作る」意味が うすれる。
- きまり:
  - ★4 に なるまで 2つ目は つけられない（ストアが ことわる）。強さの 計算でも ★4 でなければ 数えない（`wornGear`）。
  - 同じ アクセサリは 2つの わくに つけない。もう 一方に つけると、前の わくから はずれる。
  - あたらしく 作った アクセサリは、1つ目が うまって いて 2つ目が あいて いれば 2つ目に つく（★4 の とき）。
  - そうびは むかし編・現代編と 共通。2つ目の わくも どちらの もちもの（そうび）画面にも 出る。
- 強さ: アクセサリ 1つは 45点まで（`equipment.test.ts`。がまん 1 ≒ こうげき 10% ≒ HP 25 ≒ ぼうぎょ 5）。2つで 90点まで。
  - ハードは つけて いる そうびを 読んで 強さを きめる（`lib/difficulty.ts` `loadoutFromSave`）。2つ目も 読むので
    「3回 うけると 負ける」は かわらない（テスト）。
  - ふつうの お話の たたかいは 1〜5章 ぜんぶ クリアずみ。6章を 作る ときに、★4 と アクセサリ 2つを 前提に 数字を きめる。

### 3.3 クラスの 表示

- 「★」は 字（★1〜3 = 書いた 回数）と なかま（★3〜5）でも 使う。まざらない ように、ネクマックスの ★は **いつも「クラス ★4」** と 言う。
  英語（EN が ON の とき）は「Class ★4」。
- **じゅんびの レベルの 板**: 「Lv 12」の 左に クラスの バッジ（★3 は 青、★4 は 金）。タップで **クラスの カード**:

  | クラス | いつ | 何が かわる |
  | --- | --- | --- |
  | ★3 | はじめ | — |
  | ★4 | 5章の まとめの ボスに 勝つ | 見た目・アクセサリ 2つ |
  | ★5 | 10章の まとめの ボスに 勝つ | つづきは じゅんび中 |

  今の クラスの 行が 光る。EN が ON なら 各行の 下に 英語。
- **もちもの**: ステータスの「⭐ Lv 12」を「⭐ Lv 12 ・ クラス ★4」に。★4 では わくが 5つ（右に アクセサリ 2つ）。
- **★4 に なった とき 1回だけ**（`tutorials.classUp`）: 「★4 クラスアップ！」の カード。★4 の 絵と、かわった ことを 絵文字で
  （👀 見た目が かわりました・💍 アクセサリ 1つ ➡️ 2つ）。「もちものを 見る」「とじる」。
  5章の まとめの ボスの お話の あと（つづく の 画面）と、地図（お話を とばした とき）に 出す。

### 3.4 日本語

- 25課までの 文型。可能形（つけられます）は 27課 なので 使わない →「アクセサリ 1つ ➡️ 2つ」「アクセサリを 2つ つけます」。
- ぜんぶの 漢字に ふりがな（`furigana.test.ts` が 見る）。「クラス」「アクセサリ」は カタカナ。

## 5. テスト

- `lib/nexmaxClass.test.ts`: はじめは ★3・`moji-5-boss` で ★4・ほかの ボスでは かわらない。お話の ★4 の 行は その ボスの お話に ある。
  ★4 までに 習う 字が お話の「220字」と 同じ。2つ目の アクセサリは ★4 だけ 数える。
  ★4 の 絵は もとの 絵と 同じ 大きさ（そうびの 位置が 合う）。★4 では たたかいの 前に ★4 の 絵を 先読み（`episodeArt`）。
- `store/gameStore.test.ts`: ★3 では 2つ目に つけられない・★4 では つけられる・同じ ものは うつる・古い セーブは charm2 が 空。
- `lib/difficulty.test.ts`: ★4 で いちばん 強い アクセサリ 2つでも、ハードは 3回で 負ける。アクセサリ 2つは 1つより 強い。
