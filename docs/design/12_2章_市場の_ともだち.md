## 2. 舞台と 人

- **ミナトタウン**: ナニワタウンの 海の むこうの 港町。坂と 石だん、朝市、洋館、映画館、灯台。
  色は 1章と 同じ（深い 藍色の 夜空と 霧、ランタンの 琥珀色）。**霧の 町**: 字を 取り戻すと 霧が 晴れて いく。
  実在の 地名・店・看板は 使わない（08 §3.6 と 同じ）。場面の 絵は `img/port/`、id は `port_*`。
- **ソラ**: 石だんの 上の 小さな おみせ（ざっか屋）の 子。10さいくらい。英語と 映画が 好き。
  2章の「はじめての ともだち」（題の とおり）。3話で 会い、8話で「友達」を 書いて ともだちに なる。
- **ソラの 父・母**: おみせの 人（3話）。名前の 札に 2章の 字（父・母）を 使うので、書くまで「？？？」。
- 1話ごとの 町の 人（朝市の 人・ふく屋・食堂・図書館・写真屋 と お茶屋・映画館）。
- **大モジクイ**: 1章で 逃げた ボス。霧の 灯台を 巣に して いる（2-11）。絵は 1章の まま。
- ネクマックスと「あなた」（書く 人）は 1章と 同じ。決まった 流れ「〜が ひかります → あなたは かきます。ぼくが たたかいます！」も 同じ。

## 3. すじ（案）

1章の つなぎ方（困る → その 話の 字で とける → 次へ 行く 理由、08 §3.8）を そのまま 使う。

- **2-1 たかい？ やすい？**（高安大小新）: ⛴️ で ミナトタウンへ。霧の 港の 朝市。ねふだの「高い・安い」「大・小」「新しい」が 消えて、
  魚も 船も いくらか わからない。はかりを かじる モジクイ。書くと ねふだが 戻り、霧が 少し 晴れる。🐟 💰 ⚖️
- **2-2 いろの ない ふく**（古青白赤黒）: 朝市の となりの ふく屋。ふくの 色の 札（赤・青・白・黒）と「古い」が 消えて、
  町が 灰色。絵の具を のむ モジクイ。書くと 色が 戻る。👕 🎨
- **2-3 かいだんの 上の おみせ**（上下父母子手）: 石だんの 上と 下に おみせ。「上・下」の 札と 家族の 名前の 札が 消えて、
  子どもの ソラが 父と 母を さがして いる。書くと 札が 戻り、家族が 会える。おみせは「手で 作ります」。ソラと 会う。🪜 👨‍👩‍👧 ✋
- **2-4 なにが すきですか**（好主肉魚食飲物）: 港の 食堂。メニューの 字が 消えて、何を 食べるか わからない。
  ソラ「魚が 好きです」。書くと メニューが 戻る。主は「主食（しゅしょく）」。🍖 🐟 🍵
- **2-5 みぎ？ ひだり？**（近間右左）: 石だんの 小道。道しるべの「右・左・近く・間」が 消えて 迷う。
  ソラの 犬の 声が 遠くで……（6話へ）。⬅️ ➡️
- **2-6 いぬは どこですか**（外男女犬）: 港の 公園。「犬」の 札と お手洗いの「男・女」、「外」の 札が 消えた。
  ソラの 犬が いない。「犬は 外に います」。書くと 犬が 見つかる。🐕 🚻
- **2-7 としょかんで よみます**（書聞読見話）: 坂の 上の 図書館。本と 紙しばいの 字が 消えて、話が 聞けない。
  書くと 本が 読める。古い 本に 灯台の 絵。📚 👂 👀
- **2-8 はじめての ともだち**（買起帰友達）: 港の 海ぞいの 道。ソラの 日記（「7時に 起きます。市場で 買います。家へ 帰ります。」）の 字が
  食べられて、ソラが 書けない。書くと 日記が 戻り、ソラが「友達」と 書く。「あなたと ネクマックスは わたしの 友達です！」🤝 📔
- **2-9 しゃしんを とりましょう**（茶酒写真紙）: 写真屋と お茶屋。札（お茶・お酒・写真）と 紙の 写真の 字が 消えた。
  書くと 古い 写真に 霧の ない 町と 灯台が 写る。「みんなで 写真を とりましょう」。📷 🍵
- **2-10 えいがを みませんか**（映画店英語）: 映画館の 通り。英語の ポスターと 店の 名前が 消えた。「英語で 何ですか」。
  書くと 映画館が 開き、スクリーンに 灯台の 影 → 大モジクイは 灯台に いる。🎬 🔤
- **2-11 まとめの ボス**: 霧の 灯台で 大モジクイ。2章の 51字から 苦手な 10字。勝つと 霧が 晴れ、灯台の 光が 町を 照らす。
  ソラ「また いっしょに 遊びましょう」。大モジクイは 3章の 町（「読めない メニュー」）へ 逃げる → つづく。
