## 2. ネクマックスの レベル（最初から）

08 §7.1 の 案を、**最初から ある** 仕組みに する（06 §4「1話に 1つ」の 例外。とみさんの 指示）。

### 2.1 before → after

| | before | after |
| --- | --- | --- |
| 強さ | 武器・そうび・字の ★ | ＋ **レベル**（Lv） |
| HP | 100 ＋ そうび | 100 ＋ **Lv ごとに ＋4** ＋ そうび |
| がまん（許される ミス） | 話の 順 ＋ そうび | ＋ **Lv 5・10・15… で ＋1** |
| 経験値 | なし | 書く ＋1／まちがえずに 書く ＋2／期限内の 復習 ＋3／読む ターン 正解 ＋1／ボス撃破 ＋10（初回）・＋3（2回目から） |
| 上限 | — | **Lv の 上限 ＝ 1 ＋ 手に 入れた 字（★1）÷ 3**。上限に 当たると「新しい 字を 書こう」 |
| 見える 場所 | — | じゅんび（ネクマックスの 横に Lv と バー）・結果画面（EXP ＋12、Lv UP!）・ずかん／もちもの |

- 経験値は **書く ことで だけ** 入る（08 §7「強く なる 手段は すべて 学習」）。同じ 字で 1日に もらえる 量に 上限（例: 1字 1日 20）。
- 上限が「持って いる 字の 数」なので、同じ 話を くりかえすだけでは 強く なりすぎない。新しい 字を 覚える ことが 強さの 天井を 上げる。
- 必要経験値（案）: Lv n → n+1 に 20 ＋ 10n。

## 4. 難易度（Easy・Normal・Hard）

### 4.1 おすすめ: **Normal（お話）と Hard（クリア後）の 2つ**

| | Normal | Hard |
| --- | --- | --- |
| いつ | はじめから（お話の たたかい） | **その 話を クリアした あと**、じゅんびで えらべる |
| 敵 | 今の まま | HP・こうげきが **今の ネクマックスの 強さに 合わせて** 上がる（武器・Lv・★で 強く なっても 歯ごたえが 残る）。がまん −1。読む ターンは 書く ターンと 交互 |
| 出る 字 | その 話の 字 | その 話の 字 ＋ 前の 話の 字（復習） |
| ほうび | 今の まま | §3 の D |

- 「武器 その他 そろえると 敵が 格段に 弱く なる」に 答える 一番の 工夫は、**Hard の 敵の 強さを プレイヤーの 強さで 決める** こと
  （固定の ×1.6 などだと、また そのうち 弱く なる）。
- **Easy は 作らない** 案: 苦手な 人には じゅんびで もっと 書く 道が すでに あり（★が 上がると 楽に なる）、
  Easy で 敵を 弱く すると「書いて 強く なる」の 動機が 薄れる。作るなら「手本が うすく 出る」たたかい（書く 練習に 寄せる）。
- ボスだけに する 案も ある（1章の 最後の まとめの ボスに Hard）。話の 数が 増えると 全話 Hard は 冗長に なりやすい。

### 4.2 決まった 式（2026-10-03 実装。`src/lib/difficulty.ts`）

| | 式 | ねらい |
| --- | --- | --- |
| HP | 聞かれる 字（いちばん 書いて いない 字から 話の 字数ぶん）の **きれいな 1撃 × 2.5** の 合計。下限は お話の HP × 1.5 | 武器・★・Lv が 上がっても、勝つまでに 書く 回数は ほぼ 同じ（約 10回 ＋ 読む 9回） |
| こうげき | 1回で **今の 最大HP の 1/3** を けずる（盾の 防御・闇に 強い なかまの 半減も 打ち消す）。お話より 弱く ならない | 3回 反撃されたら 負け。上達は「ミスが 減る」ことに 出る |
| がまん | お話 − 1（最低 2）。Lv・おまもりで ふえる 分は そのまま | |
| 字 | その 話の 字 ＋ 同じ 章の 前の 話の 字（読む ターンは この 中の 持って いる 字から） | 復習 |
| 読む ターン | 書く たびに 1回（書く・読む・書く・読む…） | |
| 経験値 | くりかえしと 同じ（ボス ＋3、1日の 上限 あり） | |
| ほうび | 初めて 勝つと ジェム ＋50・結果に「👹 ハードに はじめて 勝った！」・`hardStages` に 記録 | §3 D |

- 印は **👹**。案の 🔥 は COMBO（たたかいの ひみつ）と お話の「火」で もう 使って いるので、重ねない。
- 敵の 強さは じゅんびで 見える（書くと 上がる）。たたかいが 始まった ときに 固定する（書いて いる 途中で 変わらない）。
- 勝ったら「じゅんびに もどる」（お話は くりかえさない）。負けた ときの 一言は「ハードは ミスを へらすと 勝てる」。
- 話の 札（ステージせんたく）の 👹 は もう一方の セッションが 足す（`hardStages`）。
- 調整は 定数 1つで: `HARD_WRITES_PER_KANJI`（2.5）・`HARD_MIN_HP_FACTOR`（1.5）・`HARD_STRIKES_TO_LOSE`（3）。

## 5. とみさんに 聞いた こと（2026-10-03 答え）

1. 難易度: **Normal＋Hard（クリア後・強さに 合わせる）**／Easy・Normal・Hard 全部／ボスだけ Hard → **Normal＋Hard**
2. クリアの 得: §3.2 の A〜D から どれを 入れるか（いくつでも） → **A・B・C・D 全部**
3. レベルの 効き目: HP ＋ がまん（おすすめ）／HP だけ → **HP ＋ がまん**
4. 1章 3〜5話の すじ（§1.2）で よいか → **この すじで 進める**

答えが そろったら、作る 順は: レベル（最初から・単独で 入る）→ クリアの 得 → 3話（デイリー）→ 4話（ガチャ）→ 5話（図鑑）→ Hard。
各段で typecheck / lint / test / build を 緑に して PR → main。
