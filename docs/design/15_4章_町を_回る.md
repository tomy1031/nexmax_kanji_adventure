# 15 4章「町を 回る」

とみさんの 指示（2026-10-05）「4章の お話も 作って」。

3章「読めない メニュー」は 料理大会で 終わり、大モジクイが **電車で となりの 大きい 町** へ 逃げて、
ハナが「わたしも いっしょに 行きたいです！」→「いっしょに となりの 町を 回りましょう！」で つづく に なって いる。4章は その 町。

4章は **16〜20課、ユニット13〜15 の 34字**（`src/data/mojiRoute.ts` の 4章。3つの ユニットは どれも 20課で 出る）。
08 §3.3 の 表では「14〜20課: て形／〜ても いい／ない形／辞書形／た形／普通体 — 友だちと 町を 回って 字を 取り戻す」。

**after**: 7話 ＋ まとめの ボス。字は 本の 順に 3〜6字ずつ。1話ごとに 16〜20課の 文型を 1つ 練習する。

- 文型は 20課まで。16〜20課の 形（て形で つなぐ・ない形・辞書形・た形・ふつうの 言い方）は 4章で はじめて 使って よい。

- 5話から、ともだちどうしは **ふつうの 言い方**（20課）で 話す。町の 人と ネクマックスは です・ます の まま。

## 2. 舞台と 人

- **京(みやこ)タウン**: マンプクタウンから 電車で 行く、となりの 大きい 町。大きな 駅、地下鉄、コンビニ、
  有名な タワー、タワーの 下の 屋台。色は 1〜3章と 同じ（深い 藍色の 夜、ランタンの 琥珀色）。実在の 地名・店・看板は 使わない。
  場面の 絵は `img/miyako/`、id は `miyako_*`。
- **町の 名前も 食べられて いる**: 台本は はじめから「京(みやこ)タウン」と 書く。5話で「京」を 書くまで 音（みやこ）だけ。
  5話の 終わりに 駅前の 大きい 看板が「京タウン」に 戻る。
- **暗い 町**（1話）: 明かりの 字が 食べられて 駅が 暗い。1話で 明・暗を 書くと 明かりが つく
  （2章の 霧・3章の 雨と 同じ「字を 取り戻すと 町が 晴れる」）。
- **ソラ と ハナ**: 3章 1話で ソラに 送った 手紙が とどいて、ソラが 1話で 合流する（ハナとは はじめまして）。
  4章は 3人（ソラ・ハナ・ネクマックス）で 町を 回る。絵は 2章・3章の もの。
- 1話ごとの 町の 人: 駅の あんないの 人・おばあさん・コンビニの 店員・地下鉄の しゃしょう・屋台の 人。
- **大モジクイ**: タワーの いちばん 上。勝つと **モジクイの 王** の 声が して、大モジクイを 連れて 消える
  （5章「モジクイの 王」への つなぎ。大モジクイの 性格「じぶんが おうさま」は じぶんで 言って いた だけ）。王の 絵は 5章で 作る。

## 3. すじ

- **4-1 くらくて ひろい えき**（明暗広多少）: 🚃 で 京タウンへ。大きい 駅が 暗い。ハナ「くらくて、ひろくて、こわいです」。
  手紙を 読んだ ソラが 来る（「手紙を 読んで、ふねと 電車で 来ました！」）。ソラと ハナは はじめまして。でんきゅうの モジクイ。
  書くと 明かりが つく。あんないの 人「町を 回って、字を さがして ください」。
- **4-2 はしらないで ください**（長短悪重軽早）: 長い エスカレーター。「はしらないで ください」の 札が なく、みんな 走る。
  重い にもつの おばあさん。エスカレーターの モジクイ（いじわる）。書くと 札が 戻り、ソラ「にもつを もちましょうか」。
  おばあさん「重い にもつが 軽く なりました」。ハナ「早く コンビニへ 行かなければ なりません！」
- **4-3 なんでも かう ことが できます**（便利元気親）: 駅の コンビニ。たなの 札が ない。じはんきの モジクイ（きまぐれ）。
  書くと 店員「この 店で なんでも 買う ことが できます」。ソラ「便利ですね！ 店員さんも 親切です」。
  ハナ「地下鉄に 乗る まえに、おにぎりを 買いましょう」。
- **4-4 のった ことが ありますか**（有名地鉄仕事）: 地下鉄の ホーム。ソラ「地下鉄に 乗った ことが ありますか？」ハナ「はじめてです！」。
  路線図の 字が なく、電車が とても おそい。仕事に 行く 人が こまる。地下鉄の モジクイ（のんびりや）。
  書くと しゃしょう「有名な タワーに 行った ことが ありますか？ タワーの 上に 大きい くろい かげが いました」。
- **4-5 どっちに いく？**（東西南北京）: 駅前の ひろば。東口・西口・南口・北口と 町の 名前の 看板が ない。
  ともだちどうしの ふつうの 言い方「ねえ、タワーは どっち？」「わからない」。ちずの モジクイ（うそつき）。
  書くと 看板が「京タウン」に 戻る。「タワーは 北だ！」「おなか すいた……」「いっしょに 食べる？」「うん、食べる！」
- **4-6 よるに なりました**（夜料理口）: タワーの 下の 屋台。「夜に なりました」「さむく なりました」。屋台の 札が ない。
  大口の モジクイ（おしゃべり）が しゃべったり 食べたり。書くと 屋台の 人「きょうの 料理は おでんです」、ハナも 手伝う。
- **4-7 みたり あるいたり**（目足曜）: タワーの 中。エレベーターが 動かない。カレンダーの 札が ない。かいだんを 足で のぼる。
  ぼうえんきょうの モジクイ（しりたがりや）。書くと「きょうは 土曜日です」。ソラ「かいだんを 歩いたり、町を 見たり しました」。
- **4-8 まとめの ボス**: タワーの いちばん 上で 大モジクイ。4章の 34字から 苦手な 10字。勝つと 町じゅうの 明かりと 字が 戻る。
  その とき 空が まっくらに なり、ひくい 声「大モジクイ、かえりましょう。字の ない せかいへ……」。大モジクイ「お、王さま！」→ 2つの 影が 消える。
  ネクマックス「モジクイの 王……？」。ハナ「みんなで 行きましょう！」→ つづく（5章「モジクイの 王」）。
